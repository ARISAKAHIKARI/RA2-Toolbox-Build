RA2 Toolbox 1.0.4 — 原生飞机路径点 / 任意建造实验版

战术助手底部新增“Hook 修改游戏判断清单”：
1. 任意建造：放宽己方建筑的基地距离/邻接限制，保留原版地形与占用检查。
2. 飞机原生路径点：启用原生路径点资格，在到点时尝试原生下一节点。

两项均默认关闭、显式勾选即自动保存，并标注“联机危险”。
飞机路径点确实需要修改游戏判断，并非只构造命令，因此也列入清单。
统一 GameRuntime 管理补丁写入、回调租约和恢复；签名冲突不强行覆盖。
原生飞机模式开启时，旧外部 Z 队列暂停并清空；失败原因显示在面板。
原生模式使用游戏规划键（默认 Z）；特殊飞机、MOD 及真实联机效果未实测。
本次没有移植平滑转弯、水面飞行或其他扩展飞机任务。

升级前关闭工具并退出游戏，再替换 EXE 与 DLL；旧 DLL 可能固定驻留在游戏中。
Update 包需覆盖到原有 1.0.2 或更新的完整程序目录。
Windows 完整包包含原有运行资源，可直接解压运行 RA2Toolbox.exe。
源代码、完整 Hook 修改清单及验证结果另见 GitHub 仓库 source 目录。
验证包含构建、架构边界、补丁签名和 x86 回调 ABI 检查；不等于实机联机验证。
