RA2 Toolbox 1.0.14 Beta
文件版本 1.0.14.0；Assist 协议 48；继承 1.0.13。

本版修改
1. 建筑/防御预定面板按实际队列和候选图标行数计算高度，增删立即收缩/展开；不再按五项上限和最大候选行数预留空白。候选过多时保留滚轮。
2. 预定窗口使用半透明显示（216/255 不透明度，约 85%）。保留独立缩放、五项 50% 叠放、编号、右键取消和 Shift 右键清空。
3. 在预定栏成功追加时播放原生 GUIBuildSound，跟随游戏音效设置。原生侧栏点击由游戏自己播放，不重复叠音；已满、失效等未成功追加不播。

音效经同一个 GameRuntime 和绑定游戏线程处理；没有新 Hook、不修改原版点击、不向 OutList 添加音效事件。音效是短时反馈，接口忙、超过 300 ms 或音频入口不兼容时跳过，不延迟补播，不阻塞预定。

安装
完全退出游戏和工具，将 EXE / GameRuntime.dll 成套更新。保留配置与 cache 目录。
Windows.zip 是完整版；Update.zip 覆盖已有 1.0.2 或更新完整版目录。
Release 附件仅运行文件和说明，源码在 GitHub 仓库 source/。

验证范围
Windows x86 交叉编译、PE/版本/ABI、统一入口架构检查；实际宿主预定服务回归与多分辨率/缩放布局检查；实际 DLL 的音效分发和原版 Produce 构造夹具检查。
没有 Windows/LBW 实机画面、实听及双机联机验收；不将模拟结果等同于实机证明。
