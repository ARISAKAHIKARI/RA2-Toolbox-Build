RA2 Toolbox 1.0.3 更新包（基于 1.0.2 Full / Windows）
文件版本 1.0.3.0；Assist 协议 43。

安装：退出游戏和工具箱，将本包 RA2Toolbox.exe 与 GameRuntime.dll 同时覆盖到 1.0.2 完整版目录，再启动游戏与工具箱。不能只换 EXE；资源目录、Python runtime 和配置继续使用原包。首次升级后，尚未成功读取过的图标仍需等游戏载入一次。

本次更新：
1. 单位图标缓存不再被每局生成的地图/临时 INI 反复失效；保留跨局内存缓存并后台持久保存。预定面板使用独立缓存文件，避免两个写者相互覆盖。
2. 智能卸载入口置灰，暂不可用；逃生助手仍独立。
3. 高级移动攻击：射程+3格索敌；已知弹头伤害比例 <=2% 不索敌；价值优先/弹头伤害比例优先可选。默认10Hz周期检测，可配1–60Hz；允许冷却期间选择更合适目标，不打断正在进行的连发。到达目的地或暂时无敌军后保持状态，新命令接管才结束。磁电轮换同样保持。
4. 增强鼠标支持左键；每项键盘绑定右侧直接选择鼠标按钮。默认原生命令先行，再追加增强任务。“覆盖原生指令”默认关闭，只在唯一管理器消息入口尝试屏蔽已验证兼容的地面命令；不删除或改写 OutList，不新增功能 Hook。不兼容、对象点击、建筑放置与普通侧栏操作保留原版。
5. Shift五连点移到战术助手，鼠标停留功能区域时状态栏显示操作说明。设置即时生效、自动保存。
6. 建筑、防御、步兵、战车四个原版生产页签在队列空闲/暂停/完成待处理时持续闪烁，恢复生产后停止。
7. 小地图左侧空闲飞机按钮显示空闲/总数；满弹停靠机场或满弹返回兼容机场计为空闲。每次点击轮流选择下一架并定位。
8. 建筑/防御各预定一个：正在建造时，原版侧栏左侧显示预定图标，点击预定；同项再点/右键取消。灰色图标是当前建筑落地后可能解锁的预览。放下当前建筑且原版实际允许生产后，经统一事件继续下一项。不改 Prerequisite，不增加热键；原版生产图标保持原有操作。
9. 飞机Z路径点：选中飞机，按Z点击地面，松Z依次执行；每架最多64点。攻击/强制攻击结束本轮设置，普通新命令接管。路径线在已有覆盖层显示。当前实现是外部路径队列，经统一 GameRuntime 提交原版移动事件，不写原生规划字段。原版规划接口和下一点处理确实存在，但尚不能确认完整飞机接收端只受前端限制，因此没有修改飞机判断或启用未经验证的规划事件组合。
10. 自动防偷点杀：战术助手勾选开启（默认关闭）。默认建筑 NALASR/GAPILL/YAGGUN，可在“功能单位清单→防偷点杀·防御建筑”自定义。射程内敌方工程师、C4、伊文、潜入类优先；已锁定这些威胁则不转走。排除盟友、隐形/运输中/失效对象；只用原始射程，不加3格。决策在外部，原版攻击通过现有规划邮箱和管理器提交，提交时复核，短期去重防止反复抢目标。
11. 变卖战车标注“兰博玩不支持”。科技全开/随处建造等原有停用项未恢复。

验证：5项便携定向测试（索敌/持久任务、点防御/比例/预览、普通攻击回归、磁电冷却、图标缓存）通过；EXE/DLL PE32、导出、共享协议/大小、版本、系统依赖检查通过；统一入口源码边界检查通过。没有进行 Windows 游戏实机、LBW 或真实双人联机验证。
