红警工具箱 1.0.30-pre.1 预发布版

本版调整
- 高级移动攻击：先选当前实际射程内的目标，再按价值或伤害比例排序。读取原版当前武器选择、精英武器、对空武器和实际射程，涵盖高度、AirRangeBonus 与最小射程。
- 射程外只用普通移动接近；进入射程后发送目的地为空的攻击事件，避免 IFV 提前交给原版追击后继续贴近。旧移动方案返回时若目标已入射程，立即作废并重新计算。
- 新增强制刷弹（测试）：支持按类型名单自动启用，以及按住快捷键对选中单位启用。当前实际武器 Burst≥2 且连射未完成时，尝试停止再恢复原目标；普通与三星武器分别按实际状态判断。
- 新增自动躲弹（测试）：对己方可移动地面单位预判敌机攻击、近距离碾压并短距避让。不限星级，可配置类型名单；暂缓同一单位的刷弹和高级攻击，威胁解除后恢复仍有效的任务。
- 两项新功能默认关闭，均支持工具箱计算或 GameRuntime 计算。共用统一游戏线程、事件入口、五类规划配额和单位仲裁；不新增游戏 hook，不修改星级、能力、ROF 或连射计数。

使用
强制刷弹和自动躲弹默认关闭，在“自动化与目标设置”中启用；单位类型在“功能单位清单”中配置。按键刷弹在“键盘快捷操作”里启用，默认 Alt+B，选择单位并正常攻击后按住；留空停用。两项均可在“高级与实验性设置 → 计算模式”中选择位置，下一局生效。

界面分为“键盘快捷操作”“键鼠组合操作”“自动化与目标设置”“显示设置”“高级与实验性设置”。顶部按钮可直接定位分区，搜索支持功能名称和使用说明。将鼠标移至功能所在行，可在底部查看操作说明。

快捷操作
键盘快捷操作：按一次执行或切换。自动装车、智能卸载等操作需先在游戏内选中单位。
键鼠组合操作：按住配置键，再用该功能的鼠标键点击目标；配置键留空时，仅点击鼠标即可。鼠标键紧邻键盘设置，可分别选择中键、侧键、右键或左键。
超级武器：按快捷键进入目标选择，再用游戏内目标光标选择位置。
组合选兵：多个类型可设为同一快捷键；单按选择屏幕内单位，双按选择全图。
轮选空闲飞机：默认 Ctrl+Alt+P，依次选择并定位空闲飞机；可修改或留空停用。

设置
有效修改自动应用并保存。计算模式在下一局生效；指令兼容模式在重启游戏和工具箱后生效，通常保持标准模式。
自动移动攻击（CS）的开关已合并，不再需要查找第二个许可开关。
状态文字、预定面板和小地图可独立缩放；小地图位置可选预设或自定义坐标。
显示设置中可选择黑幕策略；选择“地图全开（自动）”即开启自动揭示，无须再按热键。高风险功能的提示保留。

安装
完整包：解压到可写目录后运行 RA2Toolbox.exe。
更新包：先退出游戏与工具箱，将包内文件覆盖到原目录；保留配置、资源和 cache 文件夹。

验证范围与兼容说明
本版为 pre-release，供实际游戏验证。高级移动攻击、刷弹和躲避的受控回归会随源码保存；这些测试执行真实 x86 DLL、原版武器/射程函数及事件构造，但对象、输入、地图与任务观测使用人工场景，不等同于完整游戏、弹道物理或双机同步测试。
刷弹是尝试利用原版中断连射行为，效果受引擎修改、剩余连射时间和网络事件延迟影响，不保证每次成功。自动躲弹当前预判锁定己方的敌机攻击与近距离碾压，不是全弹种弹道预测；建筑、飞行中的己方单位、无可用落点、追踪弹与瞬时伤害不保证规避。大规模场景按预算轮换处理。

文件版本 1.0.30.0，Assist 协议 55，Runtime 协议 4，入口管理器协议 3。成套更新 EXE/DLL，保留配置、资源与 cache。

兰博玩刷弹效果未确认：上传的磁盘 EXE 缺少该平台启动时补入的连射重置代码。测试覆盖工具下令与恢复，不代表绕过 ROF 已实测。
