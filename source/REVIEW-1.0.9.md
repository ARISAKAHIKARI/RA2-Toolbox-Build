# 1.0.9：原生侧栏预定与预定保留修复

基线为正式 1.0.8。文件版本 1.0.9.0；Assist 协议 45，无共享结构变动。以下测试不是实际游戏或联机认证。

## 本版行为

- 建筑/防御生产中，原生侧栏图标左击可追加到该类的 5 项宿主 FIFO。无需新增热键。
- 使用 EXE 现有统一输入管理器的按下/抬起记录；只观察输入，不增加 hook，不阻止原生点击。按下已观察到正在生产、抬起仍是同一对象及图标才预定。空闲首次开始生产、完成待放置、拖动、失焦、换局、对象替换不追加。
- 读取 YRpp TabDataStruct 的滚动行/目录和原版 SelectClass 图标矩形，按实际游戏/客户区分辨率转换；原图标下方以点击穿透覆盖层显示“预定 12345”。不调用 AddCameo，不写原版队列计数。
- 补充栏仅显示已预定项目，以及原生栏没有、满足未来前置的建筑。保留每类 5 项、重复预定、右键取消该项及后续项。
- 当前建筑尚在工厂时，只依据工厂归属、产品引用和对象身份保留预约，不再拿地图存活状态/血量否决未落地产品。产品离开工厂后，须确认实际落地才提交后继 ProduceReserved。
- 对局/归属/对象身份变化、原生生产接管、当前产品取消仍撤销旧链。读取失败仅暂挂，不把失败值当作销毁证据。
- Runtime 返回 -9（原版前置、工厂或占用条件暂不满足）时保留预定，每秒至多一次重试；不再三次后清队列。请求被接受后只等观察回执，不重复生产。等前置期间补充栏仍显示队列，用户可右键取消。
- 自动日志 `Construction queue:` 记录预定来源、父对象、队首、提交、等待及撤销原因。此次修复覆盖确定存在的误取消路径；没有用户现场日志，不能断言已证明其唯一根因。

## 验证

- `construction_host_test.py`：执行实际宿主队列/目录/service/nativePointer/nativeBadges，Win32 窗口绘制 stub。ASan/UBSan；涵盖未落地生命状态、前置拒绝超过 3 次、临时读取失败、等待期间显示、5 项 FIFO/重复项、父建筑取消、右键撤销、跨局/token/重试、实际原生矩形与滚动、按下抬起/拖动/放置/首次开工/对象替换等。6 种分辨率变换。未测试 Windows 原生像素渲染或输入实时性。
- `construction_runtime.py`：36 个原版生产构造器 + 实际 x86 DLL 用例，4 种 session，CanBuild 答案和世界为夹具。校验无前置时不写事件、合法事件的类型/字段、重复唤醒不会重复提交。
- `technology_cleanup_regression.py`：6 项原版侧栏清理执行路径；未知前置图标清理发出 Abandon/AbandonAll，纯外部目录未进入该清理循环。并非完整生产模拟。
- `native_path_probe.py`：4 项原版 EXE 分支探针；C4=0/1 的爆破执行分支；生产所用 FindFactory 参数触发 buildLimitOnly=true 的 CanBuild。CanBuild 结果和对象为夹具，未模拟经济、落地及混合规划 BUG。
- UI 控件 212 个、12 种窗口尺寸、2448 个可达检查；架构检查及 PE32 版本/导出/依赖/manifest 检查通过。

没有实际 Windows 游戏、LBW 窗口重绘、双机联机或截图测试。原生生产数据布局若被 MOD 改变，本版不推测替代地址。
