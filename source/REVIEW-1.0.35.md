# 1.0.35 Release

Windows 文件版本 1.0.35.0；运行更新包只含 RA2Toolbox.exe 与 GameRuntime.dll，源码独立打包。Assist 60 / Runtime 4 / 管理器 3 协议不变。

修复另一平台 Hook 已成功回调但操作功能被启动校验整体挡住的问题：实机采集发现 21 项检查中只有清除信标入口被 MRGA1.DLL 替换。对已确认的替换函数进行完整指纹、模块归属及 ABI 兼容检查，保留平台跳转和其他严格签名检查，不改变注入方式。

关闭“卖敌方建筑”：移除入口、清除旧配置、阻断旧共享标志及 Runtime 事件授权；其他玩家单位操控继续保留。

23 项采集字节启动/ABI 检查、56 项控制/科技/出售关闭回归、主机设置测试、编译、PE32/协议/导入/清单和架构检查通过。没有本平台 Windows 实机和真实联机复测，发布不代表已验证全部平台功能。

更新：退出游戏和工具箱，将两个文件一起覆盖原目录，再重新启动游戏和工具箱。需要重启游戏以卸载旧 DLL。现有配置与资源继续使用。如仍失败，回传新版本生成的 logs/Runtime.log。
