# 1.0.28 实现与验证说明

## 行为与接口

| 功能 | 外部处理 | GameRuntime 处理 | 原版代码修改 |
|---|---|---|---|
| 喝彩 | 注册组合、输入上下文检查、统一请求 | 原版冷却检查，NoOptions 构造 AllCheer，再进入既有提交器 | 无 |
| 嘲讽 1–8 | 注册组合、统一请求 | YRpp CommandClass 数组解析原生命令，核对类型/Execute/签名后调用；不伪造网络包 | 无 |
| 半透明黑幕 | 保存策略，同步设置；小地图对未揭示区减亮 | 复用两个现有遮罩绘制边界，保留资源初始化，在原生 alpha 缓冲内绘制半透明遮罩 | 复用既有两处，无新增 hook |
| 不渲染黑幕 | 保存策略 | 复用既有遮罩跳过与上下文恢复重绘 | 同上 |

## 预定的边界

正在建造的建筑是预测根节点；已预定建筑只有在前置可达时才延伸预测，按各栏队列顺序展开，避免循环依赖自我解锁。预测只决定是否展示和保留预定，不授权生产。外部读取暂时失败时暂停检查，不把读失败当作取消；缺少前置持续 500 ms 后清理等待队列。

原有依附当前建筑的队列继续使用落地检测并间隔一逻辑帧。无当前产品的防御以及步兵/载具预定使用 ProduceDeferred，仍由同一个 Runtime 请求处理器执行。单位预定仅在明确成功回执后消费一次，不因超时猜测成功并重发。实际工厂忙时保留预定等待。

## 绘制边界

原生遮罩资源初始化和 GetOcclusion 路径保留。半透明只写 alpha 绘制缓冲，处理裁剪和环形缓冲；透明哨兵像素保留，迷雾重叠不会反复叠黑。切换策略、菜单恢复和对局变化后请求重绘。地图全开与这两种只改显示的策略互斥。

## 验证与限制

验证：新增 15 项游戏侧受控回归在两份用户 EXE 上通过，另保留每份 16 项黑幕恢复边界测试；预定生命周期与依赖清理、快捷键路由、绘制缓冲、10368 组小地图布局、PE/ABI和统一入口审计通过。
尚未进行真实 Windows 画面或平台双机联机验收，不能据此保证全部平台可用或无不同步。
嘲讽仍遵循本局禁用和其他玩家的静音设置；工具箱不会强制接收方播放。组合已被其他程序注册时会提示失败，需换一个组合。
地图全开实际调用原版揭示，会改变本地探索状态，可能产生联机不同步；半透明和不渲染仅改本地绘制，关闭可恢复遮罩。关闭地图全开不会回滚已揭示区域。
预定预测覆盖原版前置、阵营、偷科技标志及未来生产设施；模组额外科技判断仍由原版生产校验决定。兵营/工厂未落地时从预定面板顶部切换类别；不向原生侧栏伪造可生产图标。载具页同时容纳海军与飞机，提交时分辨实际生产设施。

原生参考：YRpp CommandClass.h、EventClass.h、BuildingTypeClass.h；ABI 与关键边界对照本地两份用户提供的 gamemd-spawn EXE。测试不会发布这些游戏二进制。
