# 1.0.19 Beta：战术助手操作分区与界面文案

## 操作布局

| 分区 | 内容 |
| --- | --- |
| 键盘快捷操作 | 选兵、装车、卸载、维修/逃生/自动 CS 切换、组合选兵、轮选空闲飞机、冲突策略 |
| 键鼠组合操作 | 高级移动攻击、磁电轮换、按键 CS、进驻、飞机分配攻击、飞碟、出售、飞机路径点、Shift 五连点、超级武器目标选择 |
| 自动化与目标设置 | 维修频率、矿车/矿场清单、装车分配、索敌频率/范围/优先级、渗透防御、建筑预定、飞机目标数量和功能单位清单 |
| 显示设置 | 覆盖信息、刷新率、提示、缩放、小地图位置和运行耗时 |
| 高级与实验性设置 | 实验功能及风险、计算模式、重启后生效的兼容设置 |

`assist/source/tactical_controls.h` 统一建立控件，按阅读顺序创建，也保持 Tab 遍历顺序。旧控件 ID、设置项与处理器延续使用；`extra_controls.h` 留作空的兼容 include，不再保留第二份布局。顶部五个导航按钮定位同一滚动页面，搜索同时匹配名称与悬停说明。

高级移动攻击、智能卸载的开关与绑定放在对应功能行。所有增强鼠标选择器紧随按住键。超级武器归入需要鼠标指定目标的分区。修复旧范围输入框与覆盖开关可能重叠的问题。停用且不可更改的连接模式从用户界面隐藏。

自动 CS 用一个可见开关表达旧的功能与许可两个标志。加载旧配置时以 `AutoCS.Enabled && Hooks.AutoCS` 保留原有效启用状态；点击或热键开启时继续沿用既有联动启用许可的处理器。兼容控件仍保留但不参与显示或 Tab。没有新增 INI 字段或协议。

## 文案与状态

用户界面说明只保留用途、操作、停止条件和实际限制。统一功能名称、单位和术语；Hook、OutList、EventClass、线程调度和提交回执细节不在常规状态栏展示。错误仍记录到日志，界面提供可执行的提示。没有删除实验性功能的联机风险或平台限制。

使用 `hover_help.h` 提供两行以内的简短说明。命中区域限制在实际内容视口及折叠后的下拉框高度，避免隐藏控件的说明覆盖顶部导航与底部状态。搜索可用旧名称（如自动倒矿、防偷点杀、任意建造）定位改名后的功能。

计算模式保留“工具箱计算 / 游戏内计算”两种用户选择，以及下一局生效提示。兼容模式保留重启后生效说明。运行日志保留技术诊断；新运行包的 README 是面向用户的使用说明，技术设计保存在源码文档中。更新包同时更新 README.txt，避免“使用说明”仍打开旧文件。

## 验证与边界

- 对实际 WM_CREATE、tactical_controls.h、布局函数、悬停帮助及状态函数执行便携 Win32 夹具：277 个控件，12 种窗口尺寸，3144 次可访问性检查；检查重复 ID、控件重叠、分区、按键/鼠标相邻、隐藏控件、滚动边界及悬停视口。
- 实际设置处理器与热键分发测试：自动保存、无效输入与冲突保护、组合热键、空闲飞机轮选与菜单/聊天/失焦/过期拒绝。
- Zig 0.13.0 构建 Windows x86 EXE/DLL；检查版本资源、真实清单、系统依赖、导出及协议匹配；源架构边界检查。
- DLL 代码和数据段与 1.0.18 的比较见 `verification/review-119/runtime-code-identity.json`。本版没有新增游戏注入入口或更改事件提交路径，Assist 协议仍为 51。

便携控件测试验证结构和逻辑，不等同于 Windows 字体、DPI、截图或真实游戏验证。本轮没有执行双机联机或重跑历史 DLL 场景；历史报告只对应各自版本。
