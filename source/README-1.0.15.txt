RA2 Toolbox 1.0.15 Beta
文件版本 1.0.15.0；Assist 协议 49；基于 1.0.14。

本版修复
1. 在原生建筑/防御侧栏预定时，统一 GameRuntime 会在有效预定场景接管该次左键按下/抬起，交给外部预定队列；成功追加后播放原生 GUIBuildSound，避免原版把它当作重复生产而播“Building in progress”。没有增加 Hook 或修改 EVA 语音函数。
2. 预定建筑接续生产后，观察实际工厂产品，再补齐原生侧栏当前图标的本地显示状态和工厂关联。原版绘制据此给同类其他建筑图标变灰。保留暂停状态，取消/放置后释放对应显示跟踪。
3. 退掉预定也播放原生按钮效果音：右键取消一项、Shift 右键清空各播放一次；空队列或被锁定的已提交项未取消则不播放。原生侧栏右键对应预定图标也经同一入口处理，不与原生声音叠播。
4. 预定叠放区与下方候选按钮之间加入 10 个基准游戏像素的间隔和分隔线，随用户缩放与实际游戏/客户区比例换算；保留动态高度和半透明。

交互边界
原生首次生产、建造完成后的放置、暂停后的继续、无对应预定项的右键、满队列、接口繁忙或未支持的点击仍交给原版。已经捕获的按下会配对处理抬起，拖动或切局不追加。预定成功才播放效果音；原生侧栏与外部轮询不重复预定。
事件构造仍只有 GameRuntime 统一入口负责。本次没有改生产规则、前提、工厂生产状态、接收到的仿真事件或 OutList 中的已有事件。仅更新本地侧栏展示字段。

安装
退出游戏与工具后，成套替换 RA2Toolbox.exe 和 GameRuntime.dll。保留配置和 cache。
Windows.zip 为完整版；Update.zip 覆盖已有 1.0.2 或更新的完整目录。
Release 附件只含运行文件及说明；项目源码独立保存在 GitHub 仓库 source/。

验证
Windows x86 构建、PE/ABI、统一入口审计、实际宿主预定服务及 2016 组布局组合、原生点击边界及原版绘制忙碌判定、Produce 构造夹具通过。
未进行 Windows/LBW 实机画面/声音及双机联机验收，模拟检查不等同于实机证明。
