RA2 Toolbox 1.0.10 Beta
文件版本 1.0.10.0；Assist 协议 46。升级前关闭游戏和工具，EXE/DLL 成套替换。

本版：
1. 单位统计、载员数、铁幕/冻结倒计时、敌方标记、文字播报统一按实际游戏分辨率到窗口的比例缩放。图标、文字、描边与位置一起缩放。预定面板保留原有正确换算。
2. 复核并保留 1.0.9 的预定修复：工厂中对象即使 Health=0/IsAlive=0，也不据此取消预定；前置暂不满足保留队列。补充工厂/产品复读一致性。建筑和防御各5项，普通与缺前置项目均覆盖；当前建筑取消仍取消后续项。
3. 恢复智能卸载开关、配置和热键。默认 Ctrl+Alt+U；先开启智能卸载并选中载具。乘员下车走出期间保留跟踪，走稳后部署或执行原版合法任务。停止/新命令/关闭功能停止跟进，不增加Hook。
4. 科技生产 Beta（默认关闭）：外部目录生产兵/车/飞机；不写 Prerequisite、不 AddCameo。仍要求对应工厂、供电、建造上限。提供进度与取消生产。建筑外部放置尚未验证，暂不开放。联机可测试，完整生产和同步未实测。
5. 步兵 C4 Beta（默认关闭，含联机）：默认 Alt+C + 鼠标中键点击敌方可 C4 建筑；键盘键与鼠标键可配置，空键仅鼠标。显式修改模拟校验，可能不同步或掉线；不是已复现的原版混合路径漏洞。统一 GameRuntime 管理一个签名校验补丁并构造原版任务；不修改兵种规则。关闭恢复自有补丁，冲突拒绝覆盖。

测试开关在战术助手内；设置自动保存。日志 logs/Runtime.log 中保留 Construction queue 取消原因和 c4Beta 安装状态。

Windows 包为完整运行资源。Update 包覆盖已有1.0.2或更新完整目录，保留配置与cache。附件不包含源码，源码与测试在 GitHub 仓库 source/。
针对性夹具、构建与架构检查通过；未运行真实 Windows/LBW 游戏、截图或双机联机。Beta 不保证游戏/平台接受命令，也不保证联网同步。
