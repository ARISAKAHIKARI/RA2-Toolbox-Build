# 1.0.7 整体审视与回归记录

基线：已发布的 1.0.6。重点为最近新增的逃生部署重试、地图绘制测试、任意建造/原生飞机路径点，以及它们与常规下令、菜单、换局、设置和 UI 的交互。

## 本轮确认并修复的问题

| 项目 | 复现 / 原因 | 修复 |
|---|---|---|
| 逃生偶发不再部署 | 发送队列满时，整段乘员部署处理被跳过，连短暂的序列 27 部署动画也观察不到；动画被移动打断后缺少重试依据。旧 DLL 在新回归中失败。 | 只把实际提交限制在队列/额度以内；动作观察、完成确认和移动状态继续更新。仍不写乘员任务、动画、位置；仍逐个独立首次部署。 |
| 菜单里实验回调仍生效 | 普通下令入口有菜单/对话框/战术视图检查，实验回调缺少这三项。旧 DLL 的三个边界用例均失败。 | 实验回调复用同一显示状态检查，立即返回原版分支，不必等下一次宿主采样。 |
| 停止后的遮罩刷新缺口 | 生命周期恢复了两个绘制入口，却未请求当前区域重绘。旧 DLL 在停止用例中只产生开启时的一次重绘。 | 同一有效对局、绑定线程中清理后请求一次原版 RegisterDirtyArea；不在换局、暂停、故障或无效世界中调用。原生绘图函数在测试中是桩，真实画面仍待实测。 |
| 战术面板重叠 | 实际控件构造与布局执行后，科技列表 422 和新增说明 805 重叠 7 像素。 | 下移实验功能区域，保留同一连续面板及自动保存。 |
| 截图诊断读错协议 | 诊断工具仍打开 v042 映射，且 requestToken 加入后 requestTick 偏移已变。 | 更新为 v045、80 字节前缀与正确时刻偏移；增加与当前 protocol.h 一致性检查。 |

绘制实验状态变化也加入现有宿主自动日志。没有增加补丁位置、私有 DLL、私有帧入口或 OutList 重写。

## 验证范围

本轮报告及日志在 `verification/review-107`。DLL 结果绑定实际二进制 SHA256；`REVIEW_VERIFICATION.json` 汇总数量和最终构建标识。

- 实际 x86 GameRuntime + 参考 EXE 原版事件构造器：逃生、自动装车、自动维修、倒矿、增强鼠标指令、热键全执行、类型过滤、回执、拥塞、时间、错误线程、入口绑定和重连。
- 169 项常规入口回归，含 76 项逃生用例：五乘员同格、部分成功、动画打断、排队 Deploy 去重、移动/取消/关闭、散开超时，以及四种会话模式中的满队列观察。
- 90 项开局/边界用例：普通功能组合开启、首帧零/负值/极值、菜单、对话框、观察者、运行标记、模式变化、同 House 地址换局及原生计时调用前后身份变化。普通开关集合不包含明确选择的游戏判断补丁；它们单独测试。
- 13 项绘制边界用例、7 项安装/失联/错误线程/第三方冲突用例、12 项五位置组合生命周期用例。验证本版原生重绘调用参数、开关/停止次数；五位置同时启用与独立关闭；两组部分失败回滚。
- 8 项实际绘制入口 ABI、18 项原版 Cell 绘制调用者对比、12 项已有判断入口 ABI：栈、寄存器、标志、x87/SSE 恢复，以及被观察的完整 Cell/House 字节一致。
- 62 个 C++ 算法/策略测试程序，包括射程 +3、周期索敌、2% 伤害排除、两种索敌优先级、防偷目标保持、建筑预览前置判断、闲置飞机、跨局统计和持久图标缓存。
- 压力测试在 ASan/UBSan 下检查 739,454 条分配结果、30,000 个分配场景、100,000 次预算唤醒；CPU 基准单独记录，不能当作游戏 FPS 或端到端延迟。
- 实际 UI 构造/布局检查：212 个控件，12 种窗口大小，2,448 次可达性检查；设置处理、鼠标/键盘组合、旧新地图许可互斥、鼠标左键配置和自动保存分别检查。
- 双端按帧模型：两个独立执行实际 DLL 的发送端，原版构造/OutList，模拟传输屏障和简化接收状态；也检查丢事件、重复维修、错误发送方和回放乱序的反例。接收端不是完整游戏引擎。
- PE32、版本/协议/依赖、统一入口及写入边界检查。

部分旧测试夹具尚停留在协议 42 或早期 UI，本轮更新为当前协议和真实控件/处理器。旧“所有开关都不能改代码”的断言拆分为普通功能与用户明确启用的实验补丁，保留普通功能不改代码/不直接改模拟状态的要求。

## 未被这些测试证明的部分

没有真实 Windows 游戏进程、LBW、平台双人联机、像素截图或真实输入到画面延迟测试。地图去遮罩的实际画面、重绘和每帧开销、原生飞机路径点完整执行与不同 MOD 的地址兼容性，仍需实机确认。双端模型一致不等于联机绝对不会断线。

智能卸载、科技全开、敌方建筑变卖仍停用。任意建造和原生飞机路径点仍默认关闭、标记联机危险；地图绘制测试仍默认关闭。此前讨论的装车/维修/逃生业务计算外迁并未在本轮实施。

## 升级

退出游戏并关闭工具后，配套替换 EXE 与 GameRuntime.dll。已有完整目录可使用 Update 包；新目录使用 Windows 完整包。保留配置和图标缓存。地图测试应在未执行旧地图揭示的新对局中单独开启。
