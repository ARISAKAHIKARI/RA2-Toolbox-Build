# 1.0.37-pre.3 实现与验证

以 v1.0.37-pre.2 为基础，稳定版仍为 v1.0.36。

## 攻击与生产

- 磁电交替吸允许在额外索敌范围内下达原版 Attack，不再因最小射程而排除目标。持续走位时不会被固定开火超时反复重置。
- 全局磁电保留原版攻击产生的追击目的地；手动命令仍取消自动任务。
- 检查了共用攻击入口、飞机分配、卸兵攻击和刷弹恢复。普通增强攻击补上最小射程内目标的原版 Attack；射程外保留 IFV/AA 接近后开火逻辑，减少移动目标引起的连续重发。
- 生产线正常花钱或进度推进不闪，完成待放置不闪；暂停或闲置才提示。建筑、防御、步兵、载具、舰船、飞机分别可开关。后三条共用页签，有正在生产的线时该页签不闪。
- 选择空闲飞机只选中单位，不再跳转视野。

## 操作和图像

- 工具内可编辑快捷键增加单击/双击切换：点击输入框右侧标签或在输入框右键。双击间隔 350 ms；按住类键在第二次按下后继续按住。相同物理键的单击/双击动作分别处理；同手势多功能继续受原有“全部触发”设置控制。
- 双击队形按住键、双击队形切换键可配置；同键绑定多个队形保留循环切换。队形模式继续优先消费形状按键。
- 小地图左键点击、按住拖动定位主视角；叠加层接收点击，采用最新相机位置请求。
- 局部观察窗改为纯矩形内容与边框，扩大周围采样并裁切填满，无标题、脚注或固定 11×11 菱形。
- 加入游戏目录文件读取：散文件、expandmdNN、ecachemdNN、ra2md.mix 和嵌套 MIX；支持 TMP、PAL、SHP、VXL、HVA，接入观察窗、模型预览和图标。资源包按优先级覆盖。

## 科技采集

已核验用户四阶段 probe 包，确认五处可逆代码补丁：四类图标枚举的 CanBuild 检查被替换为 TechLevel != -1，另一路侧栏移除分支被跳过。详见源码研究笔记和可复现摘要。本次没有照搬这些补丁或声称解除了完整生产/联机条件。

## 安装和验证范围

文件版本 1.0.37.2，Assist 协议 63。退出旧工具后同时替换 RA2Toolbox.exe 和 GameRuntime.dll，保留已有配置和 assets。此包是更新包，首次安装仍需完整包资源。

已通过 Windows x86 交叉编译、PE/依赖/协议检查、主机逻辑测试，以及两份支持样本中的受控原生执行。未进行本轮 Windows 视觉、实际寻路/开火和双机联机验证。特别需要实机确认各单位在最小射程内的原版走位。

加密 MIX 目前借用游戏已解密的目录索引，再从磁盘读取资源；尚未加载的加密索引不可离线解密。观察窗仍采用简化光照和固定单位朝向，不能视为完整第二台引擎相机。
