# 1.0.11：独立覆盖层缩放

基于已发布的 1.0.10，文件版本 1.0.11.0，Assist 协议仍为 46。

## 实现

| 范围 | 设置 | 处理方式 |
| --- | --- | --- |
| 单位统计 | settings.ini `[overlay] scalePercent` | 游戏像素到客户区适配后额外缩放内容；保留上、左边距锚点；狭窄窗口限制比例，避免玩家列被完全裁掉 |
| 载员、铁幕、力场、冻结文字 | Assist.ini `[Display] LabelScalePercent` | 围绕每个单位的屏幕锚点缩放缓存图像和偏移；裁剪边界同步扩大；不放大单位的世界/屏幕坐标 |
| 建筑预定补充面板 | Assist.ini `[Display] ConstructionScalePercent` | Layout 同时供绘制、面板大小、字体和点击测试使用；保留靠近原生侧栏的右侧锚点；按可用高度调整行数和面板位置 |

三项范围 50–250%，默认 100%。非法编辑保留上一次有效值，读取配置时限制范围。战术助手即时增加绘制修订号，仅磁盘写入延迟 300 ms 合并；单位统计立即标脏并保存。预定窗口在下次 Host 服务周期（约 100 ms）更新。

未改变原生侧栏点击、预定提交时序、模拟帧和单位能力。注入端没有新增业务功能；最终 DLL `.text` 与 1.0.10 相同，证据见 `verification/review-111/runtime-equivalence.json`。

## 验证及边界

- Zig 0.13.0 编译 EXE / DLL；PE32 x86、版本资源、Common Controls v6 清单、导出入口、协议与系统依赖核对。
- 执行真实设置处理函数的夹具：两项战术缩放有效值、越界值和自动保存触发。
- 执行真实预定 Host 服务的 ASan / UBSan 夹具：保留原 FIFO、父建筑取消、右键取消等用例，新增运行中改比例；7 档比例 × 6 组分辨率检查 5 个预定项和图标点击坐标、窗口边界。
- 执行真实战术 UI 构建及布局：226 控件、12 个窗口尺寸、2616 次完整可达性检查；新增控件无重叠。
- 共享视口转换与源代码架构边界核对。
- 原生路径追加研究记录单独见 `NATIVE_PLANNING_APPEND_REVIEW.md`，不计为新功能完成。

没有运行真实 Windows 游戏、LBW、双机联机或真实像素截图。本版显示改动不能以夹具测试替代实际视觉验收；历史验证文件仅代表其对应历史版本。
