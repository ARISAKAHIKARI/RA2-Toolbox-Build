## 共享范围

主屏幕渲染升级、副相机、实景小地图使用同一 `SceneBank` 原始世界快照、`SceneRenderer` 和不可变绘制参数。优先使用同对局、同所属方／地图边界、100ms 内的来源；没有其他生产者时副相机／实景地图自行采样并发布。消费者不重写源时间，也不以旧画面替代命令资格校验。

共享已推进到缩放之前：原生 TMP 素材缓存，以及原生 VXL/SHP 绘制结果（像素、深度、阴影、GPU 三角形）均可复用。结果按世界身份、不可变素材指纹、姿态、调色板、VPL、实际光栅档／后端区分；缓存 96MiB 上限和淘汰只影响命中率，不是可绘制对象名额。不同视野的裁切、遮挡、透明合成与最终缩放仍各自完成，**没有实现一张全图动态成品画布供所有视图直接裁切**。

粒子／动画、激光／光束、VXL 光影重算、SHP 光影重算四项默认开启，可分别关闭并保存，已有明确关闭设置会保留。关闭粒子／光束停止对应独立数组扫描和绘制；建筑附属动画仍保留。关闭光影重算冻结已确认的素材光照表／调色板，使用基础物体光照，不再逐帧刷新对应来源。额外画质处理、xBRZ、Vulkan GPU 维持独立选择与原有默认值。GPU 不可用可回退 CPU。

普通指令线、选框、血条、鼠标光标、建筑集结点／主要工厂、本地消息与倒计时属于主屏幕反馈，不加入共享世界素材，也不复制到副相机和小地图。

## 验证性质

- 两份 EXE：Anim 透明度 11,552 组；新粒子帧 1,024 组；消息／倒计时锚点和主要工厂／Archive 字段 196 组原生叶代码对照。
- 同一进程／对局的两个真实 Context 能返回同一个缩放前 SHP 结果引用；姿态、调色板、对局变化隔离，缓存淘汰不使在用结果失效。
- 共享副相机夹具不提供单位数组，仍从 SceneBank 得到完整场景；检查源时间不续租、过期拒绝、世界变更隔离、GPU／画质／光照参数传递。未验证物理 GPU。
- 所有阶段都不将“能编译／受控断言通过”写成实际 FPS 提升或联机无不同步保证。

Hotfix14 将四类本地 UI 的采样、字形解码、CSF 查找、排版和光栅化移到单独工作线程。四个独立紧致纹理有各自的缓存；文字未变化时复用像素引用，避免一块横跨屏幕的透明大纹理。它们不进入共享 SceneBank，不复制到副相机／小地图。字体查找表只在身份变化时重读，覆盖缓存预算仅触发淘汰；世界、视角、窗口或代次不匹配及超过 150ms 的结果拒绝显示。这里删除的是上述四类宽松保留矩形；现有激光／采矿／pips／放置网格的原生 stencil 仍在，不能泛称所有效果都已独立绘制。

## Hotfix15 队形与实现边界

队形预览继续由独立布局器给出假想位置；素材来自同一个 NativeImageBank，透明预览由主／副视图同用的 ViewportCanvas 合成。GPU、精细度、颜色精度、色盘、缩放与光照设置随不可变 Profile 进入工作线程；UI 只贴最终预乘透明位图。移除每轮四项新模型／朝向额度，按耗时与游标轮转；缓存淘汰只影响复用，不是可见单位名额。静止结果复用最终位图，公共 CPU／GPU 合成保留分数边缘的预乘透明度。它不把假想队形写进真实 SceneBank，也不推进游戏动画或发令。

本轮新程序化光束、波形、点、Alpha 和辉光目前在公共 CPU／GPU 场景输出后由 CPU 绘制；VXL/HVA 的几何光栅和队形公共画布可走现有 GPU 后端。功能可见并不代表每种新特效都拥有独立 GPU 内核。原生 A/Z、RGB565 位级混合、外晕 RNG、复杂扩展 UI 与全屏屏幕效果仍有差异。没有新的原版 EXE、Windows 游戏画面、物理 GPU、联机或 FPS 实测证明。


## Hotfix18：主视口 GPU 直出与特效批次

主视口的 GPU 场景现在可通过同一显卡的 Vulkan／D3D11 共享纹理直接交给 DirectComposition，成功时不创建或映射整帧 CPU 回读。激光、辐射线、点、辉光、AlphaShape、波纹及电弧改为有序 GPU 命令；波纹读取上一批已完成的 GPU 颜色快照，电弧在 GPU 内合成透明层后只乘一次迷雾。CPU 继续负责只读状态、源素材解码和几何命令准备，GPU 失败时使用原 CPU 回放。

Terrain SHP 的第二半阴影、动画读 Z／静态写 Z、健康值静态帧、矿石 flat/Z 和偏移均按固定 Vera20K 来源适配。没有把其整个模拟器／RNG、原生 RGB565 管线或全部屏幕效果搬入本外部工具。全图小地图、独立副屏窗口和部分本地 UI 源纹理仍保留既有输出／准备方式；不能称为所有工具窗口都已零回读。验证范围详见 [Hotfix18](research/2026-10-30-scene-hotfix18.md)，没有运行 Vulkan 或真实 Windows 游戏。


## Hotfix23：第二轮场景入口

新增FoggedObject保存图、观察者cloak/伪装/warp透明材质、原生沉船行、逐Cell Smudge、独立overlay/桥影和自定义Rubble、32槽LineTrail、PBEACON/RDRBEACN、RadarEvent、原生Cell PixelFX以及Action127 ChronoScreen。CPU/GPU回放和主/盯防共享世界均已接入口；实景雷达反馈进入GPU，示意地图在工作线程依次组合对象点、事件和信标。完整列表、来源和未完成边界见[Hotfix23](research/2026-10-31-vera-scene-extras-hotfix23.md)。
