# 动画、共享渲染与本地 UI 覆盖审计（Hotfix13）

此表区分已接入的读取／绘制路径、保留原生像素的路径和缺口。受控回归、原生叶函数对照不等于 Windows 游戏录像、GPU 驱动或真实联机验收。

## 共享范围

主屏幕渲染升级、副相机、实景小地图使用同一 `SceneBank` 原始世界快照、`SceneRenderer` 和不可变绘制参数。优先使用同对局、同所属方／地图边界、100ms 内的来源；没有其他生产者时副相机／实景地图自行采样并发布。消费者不重写源时间，也不以旧画面替代命令资格校验。

共享已推进到缩放之前：原生 TMP 素材缓存，以及原生 VXL/SHP 绘制结果（像素、深度、阴影、GPU 三角形）均可复用。结果按世界身份、不可变素材指纹、姿态、调色板、VPL、实际光栅档／后端区分；缓存 96MiB 上限和淘汰只影响命中率，不是可绘制对象名额。不同视野的裁切、遮挡、透明合成与最终缩放仍各自完成，**没有实现一张全图动态成品画布供所有视图直接裁切**。

粒子／动画、激光／光束、VXL 光影重算、SHP 光影重算四项默认开启，可分别关闭并保存，已有明确关闭设置会保留。关闭粒子／光束停止对应独立数组扫描和绘制；建筑附属动画仍保留。关闭光影重算冻结已确认的素材光照表／调色板，使用基础物体光照，不再逐帧刷新对应来源。额外画质处理、xBRZ、Vulkan GPU 维持独立选择与原有默认值。GPU 不可用可回退 CPU。

普通指令线、选框、血条、鼠标光标、建筑集结点／主要工厂、本地消息与倒计时属于主屏幕反馈，不加入共享世界素材，也不复制到副相机和小地图。

## 世界内容

| 类型 | 主屏幕／副相机／实景地图 | 依据与限制 |
|---|---|---|
| 步兵站立、行走、开火、卧倒等已支持姿态 | 共用素材／姿态路径 | `visual_pose.h`；没有所有 MOD 动作的实机验收 |
| 战车／飞机 VXL、炮塔、机身姿态和投影阴影 | 共用 CPU／GPU 场景及原生结果缓存 | 新姿态按耗时调度；不再以 8 或 256 个固定解码名额决定谁能出现 |
| 建造、卖出、基地车展开／收起 | 建筑专用状态和 make 素材 | 原生方向／帧及部件回归已覆盖，非真实场景录像验收 |
| 工厂门、屋顶、Bib、受损门 | 独立部件／计时器 | 不属于普通 AnimClass，不能只扫一个动画数组 |
| **矿场倒矿** | 建筑状态、附属动画、矿车姿态路径 | 29 个建筑附属槽已检查，含 `Anims[21]`；门／普通和屋顶卸矿素材有受控回归，完整倒矿实机阶段仍待确认 |
| 油井、常驻、充能、受损动画 | 附属／独立 AnimClass | 21 常规槽＋8 受损槽、实际 Value+Start、按身份去重 |
| 爆炸、烟雾、火焰、核弹云等 SHP AnimClass | 共用，支持原生透明度／渐隐分档 | 不将外观相似的 ParticleClass 或屏幕扭曲误当 AnimClass |
| 超时空、铁幕、心灵控制的 SHP 施放动画 | 通用 AnimClass 可处理 | 不代表单位染色、波纹、独立光束已完整覆盖 |
| SHP／VXL 弹体、导弹本体 | 弹体专用读取／素材／姿态 | 保留隐形弹体、弹道和原生存活条件；不由工具箱推进模拟 |
| **ParticleClass 的 BehavesLike 0／1 SHP 粒子** | 新增共用路径，600 个采样回归 | 采集原生有符号当前帧、细节档相关透明度及 ANIM 调色板；原生两样本 1,024 组帧选择对照 |
| 方向火焰粒子（BehavesLike 2）、像素粒子 3／4、其余 ParticleSystem | **未完整覆盖** | 不用任意 SHP／假火花代替专用原生绘制 |
| 电弧 EBolt | 三种视图共用一次端点／seed 快照并重绘 | 移除 128 条整批拒绝，验证边界 8,192；确定性视觉抖动不消费游戏 RNG，不声称逐像素相同 |
| 普通激光／光棱／LaserDraw 光束段 | 主屏幕保留原生细走廊 | 副相机／地图没有同等原生像素源，不能因 GPU 设置一致就认定光束全覆盖 |
| 矿车采矿 Gather 效果 | 主屏幕保留已确认的原生素材像素 | 不泛化为所有 MOD 矿车、移动器或卸矿效果 |
| WaveClass 磁电／声波、RadBeam、独立飞碟激光等 | **未完整覆盖** | 与 LaserDraw／EBolt 是不同类型 |
| VoxelAnim 碎片、弹跳残骸 | **未接入独立数组／完整姿态** | 已有 VXL 解码不能推导为支持碎片动画 |
| HVA 多帧动画、MOD 机甲步行／旋翼等 | **未完整覆盖** | 当前首组 HVA 矩阵不等于实际动画时钟 |
| 冲击波、时空扭曲、独立 AlphaShape／探照灯、特殊全屏效果 | **未完整覆盖** | 当前环境光照不能替代独立像素／屏幕效果 |

## 本地 UI：仅主屏幕

| 项目 | 目前处理 | 实际边界 |
|---|---|---|
| 普通移动／攻击下令线 | 功能性线段重绘 | 取消 512 人拒绝；原 Foot 此分支 animated=false，不伪造原版没有的流动动画 |
| 规划模式路径点、多段队列、路径节点标记 | **未完整覆盖** | 与普通下令线分别审计 |
| 框选、选择角标、血条、鼠标／维修／变卖／目标光标 | 主屏幕反馈层及原生鼠标素材 | 同视角／前台／菜单／世界校验；仍有不同 MOD 的额外标记未验收 |
| 飞机弹药、载员 pips | 原生 UI 素材保留 | 600 人受控场景，不声称所有 pips／老兵／组号均完成 |
| 建筑集结点 | 选中己方建筑的真实 ArchiveTarget Cell 校验；保留目标旗帜区域和连线走廊 | 不重设集结点，不调用游戏；采用宽松原生保留区，桥面／MOD 旗帜外延需实机确认 |
| **主要工厂标识** | 原生 `IsPrimaryFactory` 门槛；保留工厂及邻接标记区域 | 该小块显示原生画面，避免猜测 CSF 字体锚点；不是只提取“主要”两字像素 |
| 聊天／系统文字栏 | 标准 MessageList／TextLabel 的原生保留区 | 链表、字体尺寸、SkipDraw、稳定读取；尚未制作 Phobos 风格新聊天框，也不声称覆盖所有自定义消息插件 |
| **超级武器、任务倒计时** | 原生 DrawTimer 底部保留区 | 不改剩余时间；两样本原生坐标／字段对照，非原生字形像素认证 |
| 控制组号、老兵／精英徽章、修复／禁用／断电等额外标识 | **逐类仍有缺口／未全部认证** | 避免把普通选中层泛称成“全部本地 UI” |
| 建造放置网格、基础遮罩 | 已有原生 placement／foundation stencil | 某些射程圈、辐射／心灵控制范围、MOD 放置提示尚未全部认证 |
| 工具提示、目标名称、提示箭头、屏幕边缘指示、任务文字／胜负动画 | **未完整认证** | `Tactical::ScreenText` 及扩展 UI 仍需独立检查 |
| 侧栏、资金、电力、原版雷达、建造队列、维修／变卖按钮 | 通常在升级战场视口外，保留原窗口 | 自定义分辨率／MOD 重排需核对裁切边界 |
| ESC、选项、保存／载入、对话框、聊天输入状态 | 显示状态门控暂停覆盖层 | 已有受控前台／菜单／聊天门控回归；非所有平台弹窗的实机保证 |

## 验证性质

- 两份 EXE：Anim 透明度 11,552 组；新粒子帧 1,024 组；消息／倒计时锚点和主要工厂／Archive 字段 196 组原生叶代码对照。
- 同一进程／对局的两个真实 Context 能返回同一个缩放前 SHP 结果引用；姿态、调色板、对局变化隔离，缓存淘汰不使在用结果失效。
- 共享副相机夹具不提供单位数组，仍从 SceneBank 得到完整场景；检查源时间不续租、过期拒绝、世界变更隔离、GPU／画质／光照参数传递。未验证物理 GPU。
- 所有阶段都不将“能编译／受控断言通过”写成实际 FPS 提升或联机无不同步保证。
