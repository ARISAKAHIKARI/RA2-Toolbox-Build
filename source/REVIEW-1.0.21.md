# 1.0.21 — 功能可用性与界面分类

基于已发布 1.0.20，文件版本 1.0.21.0；Assist 52、Runtime/入口管理器 API 3 和共享结构布局保持不变。EXE 与 DLL 成套更新。

## 停用玩家控制

选择其他玩家单位、切换操控方、出售其他玩家建筑保留灰色入口，标明暂不可用。玩家下拉列表、切换和恢复按钮一并禁用，说明不再引导用户操作。

禁用不只依赖 Win32 控件状态：

- 宿主加载/同步清空三项状态，保存时不会写回出售其他玩家建筑许可；即使收到程序化勾选通知也清除勾选。
- 宿主输入不生成跨玩家选择/命令，切换按钮事件直接拒绝。
- Runtime 的选择、切换命令、建筑出售和跨玩家构造授权全部拒绝；普通己方命令路径保持原状。旧共享位被设为 1 也不能启用。
- 入口管理器删除五处选择 CALL 的补丁写入许可。科技侧栏两处 CALL 继续可用；当前最多八处精确许可位置。
- 不再采集禁用功能的玩家列表。保留协议字段和恢复实现，避免破坏 ABI；停止/故障清理仍可恢复已有上下文。

## 地图显示与飞机路径点

“地图不渲染黑幕与迷雾”移到显示设置；“飞机原生路径点”移到键鼠组合操作，与常规飞机路径点相邻，并单独显示状态。去掉两项的测试/实验性标记和测试类提示文案；功能仍可配置，默认值保持不变。

旧 INI 键继续读取和保存，避免升级丢失设置。地图显示与原地图全开互斥、原生与常规飞机路径点互斥的行为不变。原地图全开、科技解锁、扩展建造、C4 的分类不变。

本次仅调整这两项的产品分类，没有改变其底层绘制/路径点实现，也不代表新增真实联机认证。实际编译 DLL 的模拟检查验证禁用路径、原生科技流程及绘制/路径点补丁生命周期；UI 测试执行实际控件构造和设置处理。没有真实 Windows 截图或双机联机验收。结果和对应 SHA-256 见 verification/review-121/。
