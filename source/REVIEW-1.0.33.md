# 1.0.33：共用控制判定与逐功能采集器

Windows 文件版本 1.0.33.0，界面版本 1.0.33。保持 Assist 60 / Runtime 4 / 管理器 3，共享布局不变，EXE 和 DLL 成套更新。

控制全部从五个选兵 CALL 包装器改为一个共用控制入口及两个原属方查询适配器。普通选中、右键命令使用原生游戏流程；原有 Alt 手动入口保留。没有改对象 Owner、CurrentPlayer、原版事件接收器或队列格式，切换玩家继续保持禁用。

所有补丁由 GameEntryManager 安装/撤销。先安装编号查询、再启用共用判断，撤销时顺序相反；任一签名或相邻指令不兼容时回滚本组，保留外部补丁。接受原生入口和两份已提供游戏中的精确转发入口，其他修改拒绝安装。热路径只有返回常量或比较玩家指针，没有重复加锁、轮询或复杂计算。

实际地址：50B6F0、6339BA、637E40。**不写修改大师样本中异常的 6378E0/6378E1。** 637E40 是两份私有样本中经过上下文核对的合法 CALL，采用与编号查询相同的严格当前玩家比较。

RA2MasterProbe 独立升级至 0.2.0：逐项采集控制全部、地图全开、随处建造、心灵探测、科技全开、科技加强、出售或自定义功能；明确要求每步进入游戏操作；保存完整主模块、可选私有内存、不可恢复的稳定变化、操作备注和已知 2.80 样本的 PID 槽位观测。

验证：两份游戏样本各 56 项编译 DLL 受控检查，共 112 项；涵盖共用判断、两个查询适配器、原生编号查询执行、模式 0/3/4/5、普通及转发入口、关闭/停止恢复、三处冲突回滚和相邻指令不匹配。既有手动 Move/Attack/Sell 构造入队和科技侧栏检查也通过。Windows PE32、版本、清单、共享 ABI、导入和架构边界检查通过。采集器差分算法、Windows x64 编译和导入检查通过。

这些检查没有运行 Windows 游戏、完整普通鼠标命令、AI 行为或双机联机；共用判断影响范围大于原选五处入口，继续标为实验性。修改大师五项新功能的实际地址和逻辑等待新采集，并未在本版本中猜测实现。
