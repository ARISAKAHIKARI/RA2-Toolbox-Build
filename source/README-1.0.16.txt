RA2 Toolbox 1.0.16 Beta / 文件版本 1.0.16.0 / Assist 协议 50

退出工具和游戏后，成套更新 RA2Toolbox.exe 与 GameRuntime.dll；保留配置、cache 和资源目录。
Windows.zip 是完整运行包；Update.zip 用于覆盖已有完整版。附件不含项目源码。

本版：
1. 修复新进程连接中的窗口跟踪缺口：周期性重新读取 YRpp 主窗口，校验 PID/线程，正式窗口出现后重绑；旧桥保留原进程连接身份，避免 PID 复用阻塞回收。
2. 战术读取、Runtime 和单位统计持续复核类型目录；空目录、部分加载、元数据迟到及读取恢复不再只能等下一局。
3. 战术助手“显示与配置”新增小地图放大镜像，100–400%，默认 200%，默认关闭。按游戏/窗口实际尺寸换算，放在原雷达左侧，点击穿透，菜单和切屏自动隐藏；最高 60 Hz。仅镜像当前雷达画面，不扩大原版雷达探测范围。某些独占全屏或平台重绘可能无法被 GDI 捕获，尚未实机验证。
4. “计算位置”集中配置八项：高级移动攻击、磁电轮换、矿车倒矿、防偷点杀、高级进驻、飞机均匀攻击、维修筛选、装车匹配。每项可选 Runtime 或外部计算，自动保存，下局/桥接重建生效；显示本局实际位置及 Runtime 规划耗时。普通功能开关仍即时生效。
5. 所有计划继续统一原版合法性检查、事件构造、预算、回执与提交。拒绝宿主误送给游戏内后端的同类计划；同单位本帧已下令则等待下一帧，避免把额度冲突误判为目标无效。

范围说明：本版不是所有功能都已有双路径。卸载/逃生、选兵等仍有 Runtime 固定计算；预定、Z 路径、单位统计和覆盖层等仍为外部固定计算。装车/维修的“外部计算”指纯匹配/筛选迁出；依赖原版接口的采集、最终验证和重试仍在 Runtime。UI 明确标注，不提供空开关。游戏内计算会占用游戏线程，不能保证所有场景都更快。

验证为编译、PE/ABI、源边界审计和合成夹具；没有真实 Windows/兰博玩画面、双机联机或端到端延迟验收。不要把夹具通过理解为已证明不会掉线。原有实验性功能保留原标注和默认设置。
