# v1.0.30-pre.9 实现与验证

基线：v1.0.30-pre.8。文件版本 1.0.30.8，Assist 58、Runtime 4、入口管理器 3。无共享协议扩展。

## 指令行为

高级移动攻击继续使用原生 SelectWeapon / IsCloseEnough；射程外发 Move，入射程发 Attack 且清空目的地。修正旧路点或旧追击留下的进度 hold：换目标、换目的格、从攻击重新进入接近时重建进度。回归覆盖已锁定射程外目标的 IFV 模式 0/1/4/7/14。未实机复现用户的完整 IFV 场景，不能断言停步只有这一原因。

手动高移攻击、飞机分配等增强输入被接受后，每批选一个实际接受指令的单位调用原版 VoiceMove / VoiceAttack / VoiceEnter。原生语音许可与队列处理保持有效；拒绝、原生透传、自动续行不重复应答。只在输入反馈层调用，不在自动规划循环中播放。原版音频设备输出尚未实测。

原“步兵 C4”改为“步兵强制进建筑（实验性）”。取消功能层 CanC4 及旧 C4 到达补丁激活状态的提交前置条件；共用身份、所属方、对象存活、事件格式、队列容量与时序检查保留。普通步兵使用 Capture=8 并显式指定目标和目的建筑，工程师/间谍/原生 C4 分别采用对应原生任务。普通步兵不增加特殊能力，不修改规则类型。旧到达补丁不再安装；旧配置键和快捷键保留。

新逆向证据显示：Mission 17 在 CanEnterCell 阶段已经检查 C4 能力，旧到达补丁无法解决此前阻挡。实际任务分支与 Capture tick 已验证；完整路径、到达后的消失/效果尚需游戏测试，因此不把功能描述为“所有步兵能爆破”或“驻军任意建筑”。详见 research/2026-10-21-pre9.md。

## 预定、快捷键与功能配置

建筑就绪待放置时可继续预定，面板也提供原生可造建筑。点击原版当前就绪图标仍进入放置；预定生产等待建筑真正落地及工厂空闲。原版分类快捷键从实际 CommandClass 热键表读取；即使原版因为无可用单位拒绝切入某页，预定面板仍响应对应按键。

每项受单位清单约束的功能分别显示清单开关和编辑入口；沿用原有独立配置数据。删除单独“允许全图”及其快捷键入口，黑幕绘制方式统一决定半透明、透明或自动全图，旧独立全图键不再激活功能。

飞机路径点统一为关闭 / 兼容路径点 / 原生优先三选一，并增加按住键。留空读取游戏实际 PlanningMode 热键；自定义按键使用兼容路径点，不改游戏绑定。原生优先的联机会话仍按原策略使用兼容事件。

## UI 与 DPI

外层控制台按当前屏幕 DPI 缩放窗口、导航和字体，处理 WM_DPICHANGED 建议窗口尺寸。三块内嵌页面跟随宿主 DPI，用 96 DPI 逻辑坐标重新布局；空间不足时提供滚动。战术页按功能用途调整分组与顺序，单位相关提示入口保留在统计部分，高刷范围留在光标普通页。

操作说明迁移到真正的鼠标悬停工具提示，去除按钮下的说明文字；动态状态、输入范围和列表内容仍正常显示。滚动与重排禁用旧位图复制，批量移动控件后清除背景并重绘子控件，修复光标页只绘制顶端背景的问题。避免把旧位置残影搬到新位置。

## 验证边界

最终二进制哈希及逐项结果见 verification/pre9/summary.json。涵盖：

- 两份私有游戏样本上的最终实际 x86 DLL、原版事件构造器和相关原生分支；高级移动攻击、手动语音、建筑预定和强制进建筑。
- 生产设置处理器、每功能清单、路径点模式/按键往返、原生热键表拒绝损坏数据、预定 FIFO 与空页快捷键。
- 357 个 UI 控件、12 种视口、4092 次可达性检查；96/120/144/192 DPI 缩放；原版 owner-draw/字体状态路由；共享刷新率与并发发布。
- EXE/DLL 的 PE32、资源版本、manifest、协议、导出和依赖；源代码架构边界。

测试使用 Win32、世界对象及部分引擎接口替身。语音测试替代本地控制判定和非关键随机数，实际执行 Voice* 与 QueueVoice。强制进建筑测试执行原版任务识别分支与 Capture tick，未模拟完整寻路及到达效果。没有 Windows 完整游戏、真实音频设备、DPI 画面或双机联机实测。私有游戏文件不随源码和发行包发布。

后续逆向依据 AGENTS.md 先查研究索引和持久 SQLite 笔记，记录地址、样本哈希、验证方法与未决项；不回填此前旧研究。
