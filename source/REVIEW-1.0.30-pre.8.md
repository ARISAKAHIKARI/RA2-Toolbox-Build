# v1.0.30-pre.8 统一刷新率与界面标注

基线：v1.0.30-pre.7 / c9624e562e3a94f8aeefdc17a0c20224a423f53b。文件版本 1.0.30.7，Assist 58、Runtime 4、入口管理器 3。

## 同一刷新目标

统一版只使用 settings.ini 的 Display/TargetFPS（仍兼容旧 PollHz）。光标模块解析手动值或自动检测的显示器频率，发布同一个 30–500 FPS 目标。目标不再随光标呈现方式被改写为 250；原生光标的采样与交付仍保留其原有 250 Hz 上限，外置光标及画面调度使用共同目标。

宿主通过原子值保存最新频率，向战术助手所属线程发送无负载通知；接收端读取最新值并写入既有共享字段。光标或战术页面先启动均能取得相同目标；重复值合并通知，排队的旧通知不会回写旧值。重新连接时沿用当前目标。未取得光标目标前为零，避免启动时短暂使用另一份默认值。

统一构建不再拥有、读取或保存独立的 Experimental/ScrollRefreshHz，旧键保留但不参与运行；范围选择仍沿用原 RefreshStrategy。独立战术助手的兼容构建保留自己的数字输入，范围同步扩为 30–500。

Runtime 的 QPC 调度范围从 60–240 改为 30–500，ready/take 使用相同的限幅规则。500 FPS 对应 2 ms 调度间隔。迟到时跳过错过的时间片，不补发连续绘制；速度仍按实际经过时间累计，不因刷新率提高而加倍。没有新增游戏入口、同步事件或协议字段。

高刷普通页删除“画面目标”一行并收紧布局，三档范围继续位于高级设置之外。光标＋拖屏、全部均标注实验性；实际补充绘制频率和最长间隔继续显示。

## 名称与标注

载员自动逃生同步更新主按钮、计算模式、快捷键通知与悬停说明。敌方索敌显示继续使用原 Psychic 配置键，实际功能为敌方锁定己方单位的目标连线；不改游戏状态。

地图半透明、透明、自动全图逐项显示“实验性”，对应状态和说明也使用同一标注。扩展建造、步兵 C4、自动躲弹、强制刷弹、兼容模式等原风险/测试标签统一为实验性。原功能开关和执行条件沿用。

飞机路径点、生产预定、喝彩等控件删去括号中的操作说明，悬停帮助保留用法。CS 缩写、推荐和暂不可用状态保留，避免丢失功能含义与可用性信息。

## 验证与限制

见 verification/pre8/summary.json：

- 执行生产代码中的设置发布、注册通知、光标刷新率解析与 Runtime 字段同步：覆盖两种启动顺序、自动换屏、手动目标、三种范围、旧通知、未连接与重新连接；10 项显示设置路由和 10,000 次并发状态发布通过。
- 实际设置处理器分别按统一版和独立版编译运行：验证旧画面频率不再参与统一版，原范围配置和其它功能继续保存；独立版检查 30–500 合法值与越界值。
- 两份私有游戏样本上的实际 x86 DLL：每份 46 个案例。覆盖 30/60/120/144/165/240/360/500 Hz、16 ms 粗时钟下的 QPC 调度、边缘/右拖在两种范围下的 500 Hz 速度、动态改频、迟到不补帧以及原有关闭/失焦/菜单/不兼容边界。
- 最终 EXE/DLL 的 PE32、版本、导出、依赖、协议与清单检查；宿主/Runtime 架构边界检查。

Win32 输入、渲染器和部分游戏接口使用替身；这些结果证明目标传递、调用节奏与速度计算，不代表 Windows 真实屏幕已达到 500 FPS。尚未运行完整 Windows 游戏或双机联机验证。私有游戏文件不随源码和发行包发布。
