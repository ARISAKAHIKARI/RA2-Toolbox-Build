RA2 Toolbox 1.0.44-pre.3 — 硬件断点处理优化预览版

使用方法
1. 关闭工具箱并退出游戏，避免旧版 Runtime 仍留在游戏进程中。
2. 将 Update 压缩包全部解压覆盖到现有 1.0.43 / 1.0.44 系列完整版目录。
3. 保留原有 assets、profiles、engine、runtime、cache 和个人设置，再启动 RA2Toolbox.exe。
4. 主程序、GameRuntime.dll 与 GameRuntimeHost32.exe 必须配套更新，不要只替换 DLL。

主要变化
• 科技全开先查询已有的预计算允许名单；不在名单内的类型提前结束处理。
• 精确科技加强在普通维护阶段建立类型指针索引，断点回调直接查询候选记录，
  避免逐项搜索整张增强名单；不相关类型不再继续执行世界与签名检查。
• 候选命中后仍即时核对世界、对象身份、规则等级、所属数组及当前模式等必要条件。
  缓存的是候选与规则索引，不跨命中缓存一次成功授权。
• 控制回调采用编译期确定的读取器，保留原有全部即时读取及顺序，减少间接调用。
• 本方异常处理使用直接保存参数的调用上下文，保留原有 SEH 清理、嵌套深度、
  外部异常分流及寄存器恢复规则。
• 继承 pre.2 的共享原始世界样本与按需求增长的缓冲区。

诊断和验证边界
沿用 hardware-performance / world-sampling 日志中的每秒计数窗口。它们用于区分
实际异常命中量与采样工作量，不是游戏 FPS。

科技预计算和回调精简减少本工具在一次异常内的工作，不会自行减少硬件断点触发次数。
现有断点地址、槽位预算和覆盖范围保留。CPU 调试异常、Windows 派发与恢复的固定成本仍在。
本轮验证包括生产代码的受控回归、前后机器码核对与 Windows 目标编译/PE 检查；
不将这些结果作为真实 Windows 游戏、GPU 画面、帧率或联机验收。
