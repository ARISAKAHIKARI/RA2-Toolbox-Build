RA2 Toolbox 1.0.48-pre.1 · LagFix preview

以 1.0.48-pre.1 为基线，保留待合入的自毁投递修复。
这是一份独立试用更新包，不替换 GitHub 上的正式 pre.1 发布。

使用：退出工具箱，将更新包完整覆盖到原有工具箱目录，再启动。
Host、GameRuntime.dll、GameRuntimeHost32.exe 必须成对更新。
共享协议升级为 Assist105；不要混用旧版 EXE 或 DLL。
不覆盖个人 Assist.ini。需要原有全量包中的资源与游戏文件。

位置：设置 → 显示 → “单机游戏 FPS”下方。

1. 单机卡顿修复：寻路队列清理（实验性）
   批量清理原版 A* 的有效队列槽，保留原版搜索、评分、顺序和搜索编号回绕。
2. 单机卡顿修复：心控连线计算（实验性）
   减少重复坐标投影和固定曲线计算，保留原生端点、32 段连线、颜色和裁剪。

两项都是默认关闭的原生代码补丁，可单独开关。
界面显示每项是否生效和实际加速次数；联机自动停用。
原生版本或第三方补丁不兼容时保留原版路径，不强行覆盖。

本次尚未接管光棱线/心灵探测线的 GPU 绘制；也未更换寻路算法。
验证包含编译后的 DLL 与原版 x86 例程的受控对照，未做 Windows 实机 FPS、视觉或联机验证。
运行时版本号仍为 1.0.48.1；具体源码、二进制 SHA256 和验证范围见配套 manifest。
