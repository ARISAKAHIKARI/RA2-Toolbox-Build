# RA2Master 实机采集工具 0.2.0

独立只读诊断工具，适用于 Windows 10/11 x64，不需要 Python。支持控制全部、地图全开、随处建造、心灵探测、科技全开、科技加强、卖别人建筑和自定义功能。

## 使用

1. 退出 Toolbox、修改大师和游戏，重新启动 `gamemd.exe` 并进入单机对局。重新启动是为了避免上一轮补丁残留；不要为采集改游戏文件名。
2. 双击 `RA2MasterProbe-0.2.0.exe`，模式按回车，选择本轮要分析的一项功能。读取权限不足时，按游戏相同权限运行工具。
3. 建议保留默认的私有内存采集，科技类功能可能修改堆里的类型数据。每阶段最多 128 MiB、每区域最多 32 MiB；超出部分会标注截断。压缩前结果较大。
4. 依次采集：修改大师未启动 → 已启动但功能关闭 → 只开启该功能 → 再关闭。**每一步都回到游戏操作一下，再回来按回车**。例如地图功能移动视野、科技功能切生产侧栏、控制功能下移动命令。不要只在两个工具窗口间切换。
5. 记录是否实际生效、子选项及关闭后是否残留。如果关闭后不恢复，照常采集；工具会单独输出未恢复变化。
6. 推荐补采修改大师主模块和私有内存。输入的是修改大师的 PID，不是游戏 PID，窗口会显示名称供核对。
7. 压缩 EXE 旁完整的 `RA2Master-Capture-日期-时间-PID` 文件夹并回传。每项功能各做一轮；下一项重新启动游戏，避免混入前一项的效果。可以把多轮结果放在同一个 ZIP 中。

只想采集修改大师时，启动模式输入 `2`。任何一步报错都可以回传已保存的部分结果。工具不会自动上传。

## 新增证据

- 记录功能名、操作效果、备注和用户报告的游戏重启状态。
- 每阶段保存完整游戏主模块 `.mem`、逐字节可读 `.valid` 和双读稳定 `.stable`，可以查完整指令边界。
- 保留可执行节差分，新增全 PE 节稳定两两差分、关闭后未恢复差分及恢复候选，避免漏掉一次性数据写入。
- 可选游戏私有内存包含可读 MEM_PRIVATE 堆/栈等区域，按地址保存 `.mem` 和 `.valid`，需要离线对比。私有内存为单次读取，不是稳定性过滤结果。
- 可选修改大师私有内存，补充受保护回调所需的模块外数据；仍受大小上限约束。
- 对已确认 SHA 的 2.80 样本，记录特定 PID 槽位值和当时匹配的进程名；不自动断言该功能实际向该进程写入。

## 边界与验证

只以 `PROCESS_QUERY_INFORMATION | PROCESS_VM_READ` 打开用户选择的进程。不暂停或调试目标、不注入、不改内存、不调用内部函数、不抓网络包或 API 写入者。结果含程序和对局内存，直接回传分析，不要公开发布。

读取不是原子快照。稳定/恢复差分是候选相关变化，不是因果或联机同步证明；没有差异也不能排除短暂写入、未采到的堆区或其他模块。功能名称相近不代表改相同字段，按实际界面分别采集。

0.1.0 已有用户实机回传并定位到控制差分；0.2.0 完成 Windows 编译、版本/导入检查和差分算法测试，新增流程尚待用户实机运行。
