# 全视口渲染与统一覆盖层：第一阶段

分支 `experiment/render-upgrade-v139pre6-20261028`，功能线基线 `47f0e6382da9964b7a337c9c1365de4d846b9092`（源码版本 1.0.39-pre.6）。不是严格无代码补丁分支；正式版本和 latest 未改变。

## 新增入口与使用

“战场信息”中新增“渲染升级（全视口 · 实验性）”“渲染层级”“统一覆盖层（世界信息＋主屏统计）”，默认关闭，自动保存。渲染升级启用时自动使用统一画布。两个开关可以分开测试：只开统一覆盖层不启用新场景重绘。

默认层级为信息覆盖层顶部，可切换至信息层下方。光标保持最高层，避免全视口场景把指针遮住。顶层模式会遮挡其范围内的其他信息，这是显式的层级选择；需要标记和统计显示在场景上方时选择“信息层下方”。工具控制面板、侧栏、窗口边框不是新的战场场景的一部分。

全视口不是把全地图缩略图拉伸到屏幕。使用 Tactical 原生投影原点 +B0/+B4 与战场矩形 0x886FA0，从实景小地图的原生像素画布裁切。先按原生地形/精灵深度合成，再按客户区 DPI/尺寸缩放。读取实际战场区域，不用“屏幕宽度减 160”猜侧栏。显示黑幕沿用现有显示设置；本功能不调用揭示，不修改探索状态。

## 已接入的真正单窗口合成

- 新场景层。
- 世界信息层：载员气泡、状态/铁幕等文字、敌方标记、队形预览、战术提示等原有 worldrender 输出。
- 主屏单位统计面板：保留 Tab 显示、渐变透明度；后台统计模块提交不可变 PARGB 图像，不再显示原主屏统计窗口。

统一 API 是 Context + Surface：图层 ID、固定排序值、像素矩形、透明度、只读共享像素、世界/窗口/尺寸代号与可选相机绑定。生产者只发布/撤回自己的层；单独线程拥有唯一的透明、鼠标穿透、不激活窗口并合成显示。关闭模式后回到原独立窗口。

## 异步与失效规则

场景采样、MIX/图像素材处理和合成都不占游戏线程。请求只保留一个在途和一个可替换待处理项，不积累镜头请求。换局、换窗口、改变客户区尺寸会更新代号并清空旧层；相机绑定层不接受旧镜头结果。采样前后核对场景、玩家、相机、视口及帧序。新视图未完成、画面过期或坐标不可信时，场景层撤回，显示游戏原画面，不把旧地图贴在新镜头上。

窗口仅有本工具像素；不抓屏、不替换游戏渲染函数、不新增游戏代码补丁。此功能线的旧有运行时及其他功能仍保留原样，所以这不是把整个工具箱改成严格无补丁版本。

## 明确未完成

- 交互小地图、副相机、建造预定面板、飞机交互按钮、诊断窗口、光标和副屏窗口尚未迁移到单画布；继续使用旧的统一 z-order 管理，功能不偷偷删除。交互命中和副屏生命周期需要单独迁移。
- 实景素材缺失时沿用渲染器已有的占位/回退机制；并不保证与游戏原生每个像素一致。
- 原生选择框、部分特效、界面附着效果和软件光标的完整重绘未完成；本版保留独立光标层。
- 非标准渲染器缩放、全屏独占、不同 DPI、多显示器切换、复杂地形高度/遮挡及全视口性能，需要实机验证。
- 没有进行真实游戏或双机联机测试。编译、纯算法测试和 Windows 测试窗口不是联机稳定性证明。

## 验证

测试覆盖原生像素裁切、负坐标/边缘透明回退、页边界、2560 宽度、遮罩裁切一致性、缓存复用、图层稳定排序、预乘透明度、过期世界/镜头拒绝。保留原有 NativeCanvas、SceneRenderer 和 ShroudMask 回归。Windows 小程序验证单个实际透明窗口接受多层、关闭不夺焦点和生命周期清理；它不使用游戏。
