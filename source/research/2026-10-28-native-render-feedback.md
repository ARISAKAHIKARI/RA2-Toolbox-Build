# 原生操作反馈与特效补齐：第一增量

分支 `experiment/render-upgrade-v139pre6-20261028`，本轮起点 `e168c282ed2dbb98fb3af79f4e30441565f6c43f`。保持 1.0.39-pre.6 完整功能线；不是严格无代码补丁分支。本轮新增路径只做外部读取与工具箱像素绘制，不新增游戏 Hook、事件或世界写入。正式 release/latest 未改。

## 已接入

### 框选与选中反馈

直接读取 DisplayClass::LeftPressAndDraggingRectangle（Map+0x11CF）和 TacticalClass::Band（Tactical+0xD90）；读取前后核对拖动位和四个端点。支持反向拖拽、零坐标起点、战场裁切和客户区缩放，不猜鼠标动作、不发送选择指令。

通过 ObjectClass::CurrentObjects（0xA8ECB8）确定当前选择集合，复核对象 ID、Owner、IsSelected、IsAlive、InLimbo 和血量。选中边框使用已经绘制的 SHP/VXL 缓存边界，不重复解码；血条使用实际血量/Strength 和现有红黄阈值。取消选择后按当前采样撤掉标记，而不是缓存到下次场景重建。

**选中角框及血条是功能性重绘，不是原版所有兵种/建筑形状的逐像素复刻。** 地基式选择框、全部 pips、等级/控制连线及模组附加标志仍未完整迁移。单次选择集合上限 512，超出或不一致时撤回覆盖，保留原画面。

### 软件光标

使用实际 WWMouse（0x887640）的图像、当前帧、RefCount、热点，以及游戏当前鼠标色盘；校验 vtable、素材头、帧裁切和 565/555 色彩位移。只读解码真实帧，不用一支固定箭头替代攻击/移动等状态。解码有独立 Latest 工作器和资源缓存；鼠标位置使用当前客户区坐标，热点以完整 SHA 画布为参照。

软件光标逻辑层进入同一个合成窗口，位于场景及选择反馈之上。仅绘制被新场景覆盖的部分，侧栏仍保留游戏原生光标。已有可见高刷光标窗口或 Windows 硬件光标时不再复制一份；本功能不修改鼠标隐藏计数、不调用游戏 Show/HideCursor。

如果无法核实该显示的光标帧、热点或颜色，则撤回整个新场景，暂时显示游戏原画面；不把唯一光标遮掉。已有高刷光标模块仍是独立窗口，尚未强行合并它的全部模式。本次新增镜像不生成补间帧；原高刷模块的配置和效果保留。

### 电弧与原有动画

保留已有建筑动画、普通动画、维修图标和弹道素材路径。增加 EBolt::Array（0x8A0E88）只读采样：复核数组头、指针序列及对象内容，读取存储端点、颜色模式和随机种子；不修改 Lifetime，不调用游戏随机函数或 FLH 回调。

电弧采用独立确定性抖动绘制，使用现有高度投影和逐像素黑幕/迷雾遮罩。未知/完全遮挡处隐藏，透明度和 RGB 一同处理。最多采样 128 条电弧；不把截断集合冒充完整效果。

**电弧为近似视觉重构，不是原版随机曲线/动态枪口位置逐像素还原。激光、磁电波纹、辐射光束、专用粒子及全部模组特效未完成。** 界面明确显示待补，不能称为完整原生渲染器。

## 统一图层协议补强

新增 `replaceGroup(ids, surfaces)`：在同一把锁内替换或撤除场景/选择/光标这一完整组。组内缺失层会清理；过期上下文、重复 ID 和非法表面不会形成半套画面。其他世界信息/统计图层不受组撤除影响。

逻辑层顺序：场景 5 或 110（用户层级设置），选择反馈 200，软件光标 300。选择反馈和光标不随场景的顶层/底层选项被压到下面。仍只有一个被动、点击穿透、不抢焦点的合成窗口。

## 测试与限制

新增便携采样/光标缓存/选中状态/边界裁切/遮罩测试，Linux 优化和 ASan/UBSan 本地均通过 3,717 项检查。新增实际 SceneRenderer 元数据/特效遮罩/排序测试，以及真实 Windows 窗口的图层组替换、撤除、过期拒绝与关闭测试；这些结果以对应 CI 日志为准。

保留原裁切、黑幕、原生画布、小地图回归与 Runtime 文件校验，避免混入严格分支或改动联机命令逻辑。构建产物仅 EXE/DLL，日志与校验信息另包。

**尚无实际游戏画面、DPI 对齐、性能及双机联机验证。** 该补齐版本不能宣称全部特效完成、原版逐像素等价或联机稳定。测试前退出旧工具箱与游戏，再成对更新 EXE/DLL。

## 字段依据

公开 YRpp：TacticalClass.h（Band）、DisplayClass.h（LeftPressAndDraggingRectangle）、ObjectClass.h（CurrentObjects/IsSelected）、WWMouseClass.h（Image/frame/RefCount/XY2）、EBolt.h（数组/端点/Random/Lifetime）。本次只使用布局进行读取，没有调用其中的 JMP_THIS 方法。
