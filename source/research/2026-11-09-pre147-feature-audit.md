# 1.0.47-pre.3：逐功能审查与修复

## 版本、范围与结论

产品和随包原始资源继续以用户指定的 **1.0.46.4** 为基线，后续版本线为 **1.0.47**。本轮代码比较点是已交付的 pre.2 提交 `46420180d9137932ca98fd2e6c131bde4f2a6294`；新构建标识为 **1.0.47-pre.3 / Windows 文件版本 1.0.47.3**。保留 pre.1 和 pre.2 已完成的修复。

本轮按当前 UI、配置键、快捷键、协议命令、自动开关、计算位置和后台共有机制，逐项追踪入口、正常路径、关闭、失焦、断连、换局、错误恢复、身份与时效、并发及高频工作。清单区分当前可用、实验性、已禁用、仅保留配置、未接线及未实现项目。

**完成的是当前清单的源码审查和所列专项验证，不是所有功能组合的真实游戏验收，也不是“全部问题已经消失”的保证。** 已确认的新增问题完成下表修复；已知未闭合项仍单列。审查行、模式行、断言和重复循环均不作为独立产品功能数。

## 统一采样和性能边界

本轮没有降低“每个被观察逻辑帧使用最新统一原始样本”的要求，没有通过降低原始采样频率来规避缺陷。乘员绘制现在与其余信息投影使用同一份不可变世界数据；失效时拒绝/退休展示，不另起 live 世界扫描。

相机、当前选取、聊天、视口、显示检查和即时身份确认等仍有各自的只读输入。它们不被重新标记为新的世界采样时间。此处不是“所有内存读取归零”的声明；真实游戏的每一帧是否都被调度观察，以及最终 CPU/GPU/FPS，仍须现场测量。

复查了 Broker、共享输入、worker 和帧池。当前 Broker 专项 110 项、Host 重试 30 项通过；旧报告中的持锁等待缺陷已经在本轮基线修复，不能重复计为新增修复。显式轮询不做正超时等待，但同步 OS API 的 wall-clock 耗时没有绝对上限。最新请求 worker 的阻塞/失效/退出检查通过；关闭返回并 join 后不再回调。帧池只限制保留缓存数量，所有槽被持有时仍可分配临时帧，不能宣称活跃总内存有该处硬上限。

## ABI、回归和发布门槛

选兵目录 hash 和火控手动表满状态追加到共享结构尾部，**Assist 101→102**；`Shared` 从 23,162,528 字节变为 **23,162,544** 字节。新字段偏移分别为 23,162,528 和 23,162,536。x86/x64 Windows 目标分别编译提取的 **897 个布局条目完全一致**，显式布局基准和 PE 解析器负向检查通过；没有执行 Windows 映像。Host/Runtime/Broker 必须成套更新。

本轮重新执行的 **27 组发布回归全部成功**，含原有 10 组、16 个新增验证组和当前 engine 差异所需的依赖探测。巡逻容量和小缓冲 ASan 分两组记录，不能因此计为两项独立产品功能。每组都保留真实命令、退出码、原始日志和当前生产/测试 SHA。包装政策的 19 项负向/正常检查通过，拒绝缺项、过期源、变更日志、未执行声明和伪造的通过摘要。

正式交付的完整构建、PE 结果、source tree、包成员与最终 SHA 由同次交付的 `build-provenance.json`、`validation.json`、`release-manifest.json` 和校验文件记录。发布脚本继续固定 1.0.46.4 原始资源；engine 仅沿用已经审核的 `prepare_runtime.py` 差异，Full/Update 的成员规则保持。本文的专项结果不提前替代最终构建结论。

## 未闭合事项和可用性限制

- **光标混合画布像素边界修复仍未完成。** 此前原修复及缩小后的图像修复均被自动审批审查以“可能存在网络安全风险”拒绝；本轮未重试这一动作，未计作已修复。
- **联机 Sticky 退出尚未实现。** 当前可同步进入，重复键不重发，关闭和本地清理不能承诺同步退出游戏任务；单机解除是另一条路径。现有 UI 已说明此限制。
- **PRES/BUS 不显示的现场个案未闭环。** 缺少当前对局的类型、所属方、工厂及侧栏证据；不能用历史受控用例代替现场结论。
- 透明 SHA 替换入口可见但禁用，Shift 五连点隐藏，RenderUpgrade 禁用并保留部分设置，DDraw 应用/恢复未接线，切换控制玩家禁用。通用配置导入/导出和语言切换无当前入口。这些状态逐项记录，不称为可用完整功能。
- 未执行原生 Windows/WebView2、真实输入法、真实多屏/DPI、游戏命令/画面/声音、物理 GPU、硬件 DR/VEH、多人联机/OOS 或实际 FPS 验收。独立诊断 helper 的源码审查不等于该 helper 已随正常产品构建或已在游戏执行。

没有新增游戏二进制反汇编、地址、原生字段或原生 ABI 发现；已按现有索引、相关研究与持久笔记核对背景，未读取或发布新的私有游戏可执行文件和转储。项目内部 Assist 共享结构变更与游戏原生 ABI 发现分开记录。
