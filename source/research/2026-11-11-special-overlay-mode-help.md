# 1.0.51：特殊单位叠加、模式说明与入口停用

问题：特殊敌方单位需在文字标记和不透明真实外观叠加之间切换；保留原游戏图案及队形预览，不恢复旧的地形遮罩补绘。联机快捷键变卖的直接组包入口停用。所有功能模式在选择处提供逐项说明，应用图标改为彩色胶囊。

## 实现结论

- `EnemySpecialMode=0/1` 保存于 Display；仅 `EnemyMarkers && EnemySpecialOnly` 时生效。0 使用已有文字标记，1 使用独立工作线程和公共队形素材／画布绘制；关闭限定后恢复全部敌方文字标记。旧 `revealUnits` 路径仍固定关闭。
- 新叠加只画真实 Type/House 对应素材及当前坐标、各自朝向／动画。不擦除幻影树形、间谍伪装或其他原画面，不重新合成地形，不修改单位或网络事件。共用画布合成新增透明度参数：默认仍为队形预览 124，新模式为 255；素材固有透明覆盖保持不变。
- 请求绑定已发布的不可变 world token，无实时读取回退。仅独立读取 House、Scenario、logic frame 验证生命周期；缺页使本轮拒绝并向采样服务续订缺失依赖。换局、身份／所属／类型变化、关闭、聊天、离开前台时撤下对应图像。
- 未确认样本最多持有 120 ms，渲染结果跨帧年龄上限 150 ms；暂停同帧仍可复用，明确空集立即清空。4 ms 素材预算按轮转处理；预算不足时仅复用同一活单位 150 ms 内的旧姿态，使用新位置且不续期，避免分批绘制导致轮流消失。
- `SellAvailable=false` 同时作用于设置读取、保存、按钮消息、共享标志及 Runtime 准入。按钮置灰且状态显示暂不可用。原生变卖光标保持独立路径，未修改其行为。
- 控制台增加按完整选项清单匹配的模式说明目录。当前模式说明常显，下方“比较所有模式”可在选择前展开；拒绝操作会回到实际选项说明，置灰模式仍可阅读但不能被说明操作启用。未知清单不继承其他功能的说明。说明使用纯文本，不执行 HTML。
- 可编辑胶囊 SVG 经 librsvg/Cairo 生成 16、20、24、32、40、48、64、128、256 九尺寸透明 ICO。资源组 101 与窗口加载路径保持不变，界面品牌标识使用同源 SVG。

## 地址、字段与 ABI

没有新增 native 调用或协议字段；Assist ABI 107 不变。沿用已有字段：对象 ID `+0x10`，HP `+0x6C`，alive `+0x74`，limbo `+0x81`，on-map `+0x90`，坐标 `+0x9C/+0xA0/+0xA4`，transport `+0x11C`，真实 House `+0x21C`，cloak `+0x220`，disguise `+0x1D8`，Type PermanentInvisible `+0xC9A`，Infantry Infiltrate `+0xEBE`，类型 ID `+0x24`。旧伪装类型／所属 `+0x518/+0x51C` 不用于新模式的素材选择。

生命周期沿用 `0xA83D4C` 本方、`0xA8B230` 场景、`0xA8ED84` 帧号。历史笔记支持映像 SHA-256：`268a81b7422b3bb855e1b4a162aadba4d807f88fb9f70feb99118211d8fbb8d0`、`c287d62a4d6a25b547e9339d071dd6e03adcf545699062e478aaeee38c60e89a`。本轮没有执行这些私有游戏映像，没有新增反汇编结论。

## 证据与边界

- `assist/tests/special_unit_overlay.cpp`：实际 Renderer/compositor，受控素材、真实 Snapshot 缺页语义；真实类型、独立朝向、255/124 透明度、死亡／装载／复用／不可见类型、预算保留及过期、位置与视口过滤、不可变图像检查。
- `assist/tests/special_overlay_lifecycle.py`：抽取生产状态处理，受控异步结果；冷启动、无变化复用、120 ms 保留、明确空集、旧完成结果、世界／设置／身份变化及聊天／焦点清理。
- `assist/tests/special_overlay_settings.py`：执行实际显示控制、所有者消息和 INI；旧变卖配置、伪造按钮消息、共享标志均不能开启停用入口。
- `suite/tests/choice_descriptions.cpp`、`choice_help_test.mjs`：实际描述数据、JSON 与前端事件／状态协调；当前及全部模式说明、待处理选项、拒绝回退、禁用选项、旧快照、纯文本输出。
- 继承采样、气泡、输入与原队形测试；完整编译、PE 和最终测试结果随发布包记录，不用源码检查冒充实机结论。

当前环境 Chromium 启动因本地 socket 被拒绝而失败；前端交互通过受控 DOM 检查，未进行浏览器布局截图验收。胶囊图标已通过本地 SVG 栅格化及透明像素／尺寸检查并目视检查。未进行真实 Windows 游戏视觉、实际系统按键或联机验证。仍需实机确认素材齐全时的外观、前后遮挡及性能；保持原画面意味着旧树形／伪装可能仍从叠加轮廓旁露出，这符合本次追加显示的范围。
