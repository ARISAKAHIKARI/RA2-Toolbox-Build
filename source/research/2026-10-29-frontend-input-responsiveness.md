# 前端拖动、开关依赖、快捷键手势与页面滚轮

## 问题与证据边界

用户报告工具箱自身拖动卡顿、子选项没有依赖约束、快捷键无法区分按下／松开／持续按住及双击，组合键说明不明确；追加要求滚轮只上下滚动页面，不修改配置。

基于 Render Fix4 的 x64 宿主／x86 Runtime 分支继续，交付版本为 1.0.39-pre.7。此次调查对象是工具箱 UI 与现有输入路由，没有新增游戏函数地址、字段偏移、二进制样本或游戏代码段写入。共享结构、Assist 80／Runtime 4 及原有命令入口保持；更新时仍须配套替换组件。受控 Win32 窗口和软件 Vulkan 检查不等于用户桌面视觉、游戏帧率、NVIDIA 模型执行或多人联机验收。

## 拖动与布局

原宿主把三个模块 UI 线程的窗口设为跨线程子窗口。微软说明这种 parent／owner 关系会附着输入队列。由此推断，忙于读取、绘制或设置处理的模块能够拖累宿主输入；这不是对用户机器具体卡顿耗时的实测。

新 `suite/source/frontend_panes.h` 保留独立、无跨线程 parent／owner 的设置窗口。宿主只发布最新布局，不同步调用模块窗口。模块在自身线程生成完整控件 DIB；移动／缩放时宿主显示最后完整快照，后台业务继续。

宿主通过动态取得的 DWM cloak 立即遮蔽旧坐标窗口，只有宿主可以恢复可见内容；必须同时满足未交互移动、前景属于工具箱、没有待处理／正在处理的布局、已完成布局等于最新请求。修正了 A→B→A 和显示过程中切走页面时基于旧 applied 状态错误去重的竞态。DWM 不可用时回退异步隐藏，不能宣称此回退也有即时遮蔽保证。

拒绝只做重复布局去重作为纯拖动问题的完整解法；也拒绝仅异步隐藏却声称忙模块旧窗口已经立即消失。

## 配置依赖与滚轮

`settings_dependencies.h` 统一判断 60 个子项，`dependency_controls.h` 把策略应用到真实 HWND，`ui_dependencies.h` 接入初始化、变更和节流刷新。禁用保留用户保存值，提供原因；父项恢复后重新可用。合成通知也经过策略检查，不能仅依靠控件灰色外观。

DLSS5 需要 x64、渲染升级、Vulkan 与精细场景。Vulkan 同时可服务小地图；副屏输出、危险乘员气泡、全局磁电和一次性维修相关选项不被错误绑定到无关父开关。修改绑定不再替用户开启高级移动攻击或智能卸载。发布到 Runtime 的相关从属选项使用有效值，INI 保留原选择。

`shared/source/page_wheel.h` 拦截设置控件滚轮并投递给所属页面，包含下拉列表的编辑框与弹出列表、数字框、微调控件和快捷键框。每页分别积累不足一个刻度的滚轮量，边界处仍不把滚轮交还给配置控件改值。

## 快捷键格式与行为

16 位绑定继续保留低字节 VK、Shift／Ctrl／Alt 和原 `HOTKEYF_EXT=0x0800`，双击仍用 `0x8000`；新增 `0x3000` 模式掩码：Press=0x1000、Release=0x2000、Hold=0x3000。零模式维持上下文中的旧语义：一次命令为按下，持续授权为按住。

单次命令只提供按下、松开、双击第二次按下／松开；持续授权只提供按住／双击第二次按住。队形形状仅支持键盘按下／双击按下，编辑器不暴露假支持的松开或鼠标手势。描述明确修饰键保持按住，再对主键执行动作。保留原快捷键 INI、旧选兵隐式单按屏内／双按全图；混合显式成员时整组采用显式语义，与条目顺序无关。

释放事件使用即时物理状态；不把滞后的游戏输入快照零值误认成按下后的释放。失焦、聊天、旧对局、断连和重配取消未完成手势并清选兵双按缓存；修饰键先松开时持续授权解除，不能被旧自动重复复活。主键和修饰键在一次采样间都已释放时，释放型组合保守拒绝，不猜测顺序。

原有消息入口记录键盘及 L/R/M/X 鼠标边沿，未增加游戏 Hook。光标提示改用与执行相同的已修饰按住状态。队形保留独立双击 Alt modal 和已经捕获鼠标手势的冻结预览提交。

预设／自定义绑定保存改为显式 raw 手势路径并同步预设显示。不能把原自定义框路径描述成已复现“必定丢模式”：此前已有切换到自定义预设的副作用；本次明确该数据流并验证新位、重复绑定和批量保存的一致性。

## 验证路径与未决项

- `frontend_controls_windows.cpp`：真实原生控件、滚轮不改值、弹出列表、手势捕获／菜单、禁用值恢复与提示位置。
- `frontend_panes_windows.cpp`：真实独立 UI 线程、忙面板响应、10,000 次布局合并、完整控件像素、DPI、A→B→A、迟到显示、前景／最小化／关闭；DWM 不可用单列 SKIP。
- `key_gesture.cpp`、`hotkey_routes.cpp`、`type_hotkey.cpp`、`native_key_gesture_test.py`：边沿、修饰键、双击、焦点／对局、旧绑定及混合组。
- `hotkey_host_test.py`、`secondary_display_host_test.py`、`formation_switch_test.py`、`command_cursor_host.cpp`：实际生产路由、释放／双击释放、队形退出和双击按住提示。
- `settings_dependencies.cpp`、`auto_settings_ui_test.py`、`suite_display_test.py`、`ui_geometry_test.py`：依赖、保存与转发、469 个控件／12 种视口可达布局。几何测试更新了过时接口和原已恢复的卖出开关；长说明由独立 tooltip 换行，不再要求塞进两行状态栏。

最终验证记录随测试包和同一持久笔记附加，不能把交叉编译说成实际 Windows 执行。用户机器的拖动观感、DWM／多显示器环境以及真实游戏操作仍需现场验证；既有 DLSS5 也仍未做 NVIDIA 模型实机验收。
