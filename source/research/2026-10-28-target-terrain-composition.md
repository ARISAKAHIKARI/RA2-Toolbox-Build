# 主视口高分：TMP 与地面覆盖物直接合成到目标像素

继续渲染升级分支；实现起点为 `7a94293` 的实际倍率与连续 RGB 光照。用户本轮暂缓 DDraw 接管，优先改善颜色和高分质量。本项仅修改外部渲染器，沿用已经解码的 TMP、SHP、调色盘、格子光照和深度数据，没有增加引擎地址、调用、Hook 或世界写入，也没有新的逆向发现需要追加 SQLite。

## 缺口与改进

此前精细档的动态 SHP/VXL 已直接在物理视口合成，但 TMP 与静态地面 Overlay 仍先进入原始像素分页画布，最后把整块背景统一放大；地形 Z 同样来自原始像素。这样无法保留逐素材透明边界、覆盖物与局部光照在最终像素上的合成顺序。

精细主视口现在从空的目标像素底板开始，按原有格子排序绘制 RGB underlay、TMP、地面 Overlay 及其附属图像，再绘制动态对象与最终战争迷雾。直接复用 `tiles_`、`overlays_` 和格子光照求值，不重新解析全部素材。原始分页背景继续作为兼容档与离屏缓存使用。目标底板不包含已经绘制过的原始背景，因此不会在原有阴影上再叠一次同一阴影。

目标背景颜色与深度一起缓存。视口、实际比例、像素模式、地形／高度／覆盖物、现场光照、色盘及颜色精度改变时刷新；没有变化时保留已解码素材和完成的目标背景。动态对象每次从这份背景恢复，避免残影。已知素材的完整裁切框与附属图像参与 cull，Overlay 的高度偏移也计入可见范围；大 extra 从视口外伸进画面时不能只按 60×30 菱形或格子中心丢弃。

“最近邻”现在也传入动态目标像素对象，普通 SHP 不再强制使用自适应采样。模式 2/3 使用自适应，模式 0 保留既有对象采样规则。真实高密度 VXL 仍可独立做覆盖率 resolve；它是几何样本的缩合，不等于替 SHP 打开平滑。

## 边界与预算

- TMP、地面 Overlay 直接取已有源图像的目标像素样本，没有生成原素材不存在的纹理；本轮不是 xBRZ 或 AI 超分。
- TMP 与 Overlay 的源 Z 保持最近邻。悬崖、桥与不同图层之间不混合深度，不能把目标像素合成误称为新增了原生地形深度细节。
- 单轴最多 8192、输出最多 16M 像素、实际放大不超过 4 倍。目标地形构建另有 65,536 个可见绘制命令、128M 个裁切后像素访问及 16 层附属图像深度上限；新素材仍受每轮 64 项解码和已有源像素预算限制。
- 可见素材缺失、目标构建超预算或现场光照校验失败时返回空结果，由宿主撤去外部画面显示原游戏；不能把粗色底板冒充完成的高清场景。未完成的目标缓存也不能在下一次调用中被当作有效背景复用。
- 静态场景和动态场景都裁掉合法原始 backing 之外的像素；最终黑幕仍最后施加。

## 验证

`terrain_viewport.cpp` 运行实际 `SceneRenderer`，用可公开的合成 TMP/Overlay 检查 1:1 原始／精细等价、1.5/2/3/4 倍目标像素参考、透明 extra、地面阴影只执行一次、原地色盘和环境光改变、60 单位深度断层、视口外大 extra、动态最近邻／自适应差异、静态 backing 透明边界、最终黑幕与构建预算失败后的缓存恢复。

既有 `radar_scene`、`native_canvas`、`viewport_detail`、`material_scene`、`live_scene_lighting`、`live_voxel_scene`、`color_scene` 等回归继续覆盖分页、排序、遮挡、素材重试、现场光照和精度模式。受控像素测试与 Windows 交叉编译不能代替真实游戏的画面对比、性能和联机验证；本项不宣称已经实测 120/240/500 Hz。
