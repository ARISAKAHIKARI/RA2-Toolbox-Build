# 严格无游戏代码写入版本

分支：`experiment/no-inline-game-patches-20261027`。本轮基线：`ef48294ff2727522ed2d85d712fe2c1df31b1237`。

## 本轮约束

`GameEntryManager` 的旧可执行内存写入器已从源文件删除。所有 `Operation::Patch` 请求在检查请求 ABI 后立即拒绝，早于读取目标地址、申请执行许可及调用 Windows API。安装、恢复、旧配置请求、已持有补丁的恢复请求均无例外。导出 `GameCodeWritePolicyInfo={1,0,0}` 供静态核对。

保留原生事件提交、Windows 消息回调和数据读取。禁止的不是“DLL 内执行代码”，而是本工具改写游戏指令。游戏原生函数可能更新事件队列及世界数据；本版本不是“完全不写内存”，更不是已验证的联机安全版。

旧 Registry 的安装/恢复分类与纯元数据测试仍保留，供诊断使用；运行时不再调用其 `mayApplyPatch`，也不提交注册表安装记录。它不能授权实际写入。读到第三方补丁时不尝试覆盖、还原或规避任何检查。

## 必须冷启动，不支持覆盖旧进程热升级

GameEntry ABI 从 3 改为 4，Runtime IPC 从 v4 隔离至 v5；结构尺寸保持不变，但旧运行时不会使用新的 IPC 名字。必须退出游戏与旧工具箱，再成对替换 EXE/DLL。严格版不会为旧进程恢复代码。出现补丁残留或冲突时，界面保留原始诊断并提示重启。

## 功能完成度

| 功能类别 | 当前状态 | 说明 |
|---|---|---|
| 新安装及恢复游戏代码补丁 | 已实现拒绝路径；待真实进程验证 | 原写入器已删除，不通过其他写入 API 绕过 |
| 装车、维修、矿车卸矿 | 原生事件路线保留，待实测 | 不是本轮重写算法；满载、人工介入、重复事件及双机同步未完成验证 |
| OutList 观察 | 仅诊断 | 按帧限流；可见候选不是人类操作证明，不取消自动任务 |
| 原生手动命令接管自动任务 | 无补丁等价替代未实现 | 不使用鼠标点击猜测；“停止所选自动任务”仍是显式操作 |
| 控制全部、随处建造、原生索敌改判定 | 无补丁替代未实现，相关独立开关置灰 | 不能用禁用代替宣称修复 |
| 事件所属方保留、控制命令所属方、对手建筑原生出售光标 | 无补丁替代未实现，相关开关置灰 | 不新增协议或改变接收端权限 |
| 透明/半透明黑幕、直接全图 | 无补丁替代未实现 | 混合模式选择器保留，状态明确不可用 |
| 原生揭示 | 数据修改路径保留，有同步风险 | 不等于纯显示或已同步的网络揭示 |
| 科技加强 | 类型数据修改路径保留，有同步风险 | 数据恢复不等于代码补丁恢复；失败继续显示 |
| 科技解锁 | 无补丁替代待审计 | 不将所有旧实现一概认定为可用 |
| 兼容飞机路径点 | 事件路线保留，待实测 | 原生改判定模式无补丁替代未实现 |
| 其他自动化/组合操作 | 显示待实测 | 不承诺原有全部功能已迁移；共享发令入口仍受原有校验约束 |

已保留原设置、快捷键和布局。不能从“勾选”推导“生效”，也不能从“可构建”推导“联机稳定”。正式 release 与 latest 未改动。

## 测试范围

新增单元测试将真实 `game_entry_manager.cpp` 与测试专用 Win32 模型一同编译。覆盖合法执行许可、模拟遗留已持有补丁、非法目标/长度/客户端、锁忙和旧 ABI，断言 Patch 拒绝时请求、管理状态与注册表不变，并且没有 Windows API 调用。

源码约束扫描所有既有生产模块目录，包括管理器本身，拒绝已知可执行内存写入 API。它不能证明任意原生函数或第三方 DLL 从不修改内存，也不是整个游戏代码段的实机校验。

UI 测试覆盖未实现/待实测/待审计标签、残留冲突提示、数据修改警告，以及设置未被状态适配器更改。现有分批维修观察、OutList 采样预算和原生事件路径测试继续保留。Windows workflow 的实际结果与产物以对应提交的 CI 为准；没有进行真实游戏或双机测试。
