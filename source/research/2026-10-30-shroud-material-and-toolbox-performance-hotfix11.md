# Hotfix11：迷雾素材替换与工具箱性能

## 问题与调查范围

用户要求将透明／半透明迷雾素材替换接入产品，并检查工具箱其他读取与性能瓶颈。基线为远端 `4126f519c9325d4ec264406846c1a883af5aeff5`。调查前查阅研究索引、原版迷雾和联机审计、Hotfix10 记录及持久逆向笔记 v86。本笔记新增的原生证据支持私有样本 SHA-256 `268a81b7422b3bb855e1b4a162aadba4d807f88fb9f70feb99118211d8fbb8d0`；不发布原 EXE 或内存转储。

## 原生资源结构与调用

对该样本做静态反汇编：`0x69E740` 为 SHP GetData，thiscall 的 ECX 为资源引用，接收帧索引并返回数据指针；若引用首字为 `0xFFFF`，先检查 `+0x10` 的已加载字节、通过 `+0x0C` 取解析后的资源指针；再经 `0x69E580` 解析，核对资源头 `+6` 的帧数，逐帧头从 `+8` 开始、每帧 24 字节，数据偏移为帧头 `+0x14`。GetData 直接返回资源基址加数据偏移，不在这个叶函数解压 RLE。

黑幕叶函数 `0x47EFE0` 和雾叶函数 `0x47F250` 是 thiscall，栈参数为绘制点、裁剪矩形和帧号，`ret 12`。懒加载初始化标志分别为 `0x89E7C5/0x89E7C6`；资源槽为 `0x89E790/0x89E794/0x89E760`。样本在懒加载开头已有平台改写跳转，受控绘制测试从已加载资源状态进入，不能推断未加载时整个 loader 的行为。槽位历史用途见既有原生迷雾笔记；这里不猜测其他游戏版本的二进制相容性。

`assist/tests/shroud_material_runtime.py` 对实际新 Runtime 和原生绘制叶函数使用合成资源：两个会话类型、两种素材模式，检查全部 47 帧的载入数据、原生黑幕／雾的像素输出、平稳帧无重复写入、透明与半透明之间切换、切换旧绘制模式、关闭和 Runtime 停止恢复、资源槽指针不变、可执行段不写入、未产生事件。`assist/tests/shroud_material.cpp` 另用两个完整 47×60×30 原始透明平面验证懒加载、同一外层引用的资源更换、部分写入失败回滚、压缩帧／重叠区域拒绝、外部写冲突与释放后复用隔离。前者模拟已加载资源和 Win32 边界；后者是 C++ 内存替身。二者均非 Windows 实机、实际文件加载或网络联机验证。

结论：新增两个显式选择项（默认关闭）。控制器保留游戏资源指针与分配方式，备份并仅改动可验证的 60×30 SHP 的原始 alpha 平面。透明将 0..127 设为 127，半透明为 `(alpha+128)/2`，高于 127 的跳过值保留；不修改 Cell 探索状态，不调用跳过黑幕绘制的分支。素材半透明作用于原生画面；当前渲染升级、副相机及小地图仍沿用既有全图预览策略，半透明遮罩不在这些画面重建。资源槽改变、选项切换、关闭与正常停止会尝试恢复。只允许已提交、可读写、非可执行页，并拒绝未知、压缩、交叠或不完整结构；外部对素材的冲突写入不会被强制覆盖。无法证明陌生 MOD 资源、异常强制终止、同地址同头复用或平台防护兼容性。

## 性能修改

- 单位统计采样与图标解析移至独立 Latest 工作线程，独立 ReadSession；UI 消费带 PID／generation／进程连接代次／采样时效的不可变快照，主副屏复用同一个快照。断开与重连丢弃进行中的旧代结果。仅重试时间或缓存内部标志变化不会触发重画；原本 250ms 采样节奏未改变。
- 生产队列的 512 类型查找建立指针索引，保留重复指针的原有首项语义。一次合成基准：100 万次查询、512 类型，原线性查找约 222.2ms，索引约 2.66ms，结果校验和一致；只描述这段 CPU 工作，不能推算真实游戏帧率。
- 副相机保留完成的 VXL 图像，只有 VPL 修订和可用性、色盘、完整朝向／姿态等足以确认相同时复用；光照不可读时沿用保守重算及失败隐藏。静态地形／覆盖素材去重，避免重复检查和缓存清理时的嵌套线性扫描；普通素材工作仍有 6ms 软预算，不再强制每次仅 16 项。
- 随机进程识别的缓存锁不再覆盖磁盘文件读取；受控慢文件读取不会阻塞其他进程的缓存命中。计算状态文本的构造节流为 250ms，设置变化立即刷新，不改变命令执行节奏。

相关受控测试包括 `unit_monitor/tests/async_sampling.cpp`、`unit_monitor/tests/round_transition.cpp`、`assist/tests/secondary_stats_test.py`、`assist/tests/watch_live_palette.cpp`、`assist/tests/watch_host.cpp`、`assist/tests/watch_async_test.py`、`tests/process_identity_lock.cpp` 和 `tests/random_process_discovery.cpp`。架构审计把唯一素材写 API 限定在 Runtime 的该项非执行页功能；旧网络发送入口和系统 Vulkan loader 已存在，审计允许清单同步源码事实。

没有进行真实 Windows 游戏画面／性能、GPU 硬件 FPS 或双机联机验证。
