# MO 功能整合与协议84

## 问题与固定来源

用户要求将 MO_ExperienceEnhancements 的缩放、模糊下令、目标分配、快速占位、巡逻、地图防抖、飞机路径点、超武分栏、暂停逐帧和侧栏隐藏加入当前工具箱。基线为 Hotfix33 `17ee48810d33d47203d52893d3b0472d992f3a11`；固定上游 `33ed558bd38f36b5012eddcc9c0fb109cc68e38a`。调查前已检索研究 INDEX 与持久笔记 v114。

## 整合边界

- `assist::Version=84`，Shared=6584440 字节；Runtime=4、entry manager=3 未变。Host/DLL 通过导出结构与 v084 命名空间核验配对。
- 尾部新增 `moFeatures`、订单状态/计数、原子预览、物理A/逻辑R视口及单机暂停状态；窗口和游戏指针仍为32位值。
- `bridge.cpp` 统一接入 tick、输入过滤、重置与异常恢复；待构造巡逻进入既有帧调度/世界索引条件，所有发令走原有中央传输与单位仲裁。
- Host 绘图线程捕获不可变预览和视口变换。世界信息、队形、路径映射R至A；侧栏徽章和状态提示保留物理坐标。100%恒等变换不扩大世界覆盖层的裁切区域。
- Host 旧中键轮询与新 Runtime 手势共享归属判断。F11 切换侧栏；F5/F6 暂停和逐帧由 Runtime 单机白名单接管。
- 停止时先等待原生绘图租约退出，再确认卸载；资源还原不得因共享映射已断开而跳过。递归 Display::Render 直接交给外层完成，防止 A/R 表面错配。
- 侧栏新面初始化失败不发布；地图缩放命中尺寸上限时，状态报告实际有效倍率。

## 验证及限制

实际 Windows x86/x64 编译布局的704项大小、对齐和偏移检查通过；导入表、版本、架构、清单和通信导出检查通过。相应模块另有几何、容量、输入归属、队形续走、超武状态及暂停策略的受控检查。

未新增可执行文件兼容性哈希声明。新原生调用沿用既有已记录布局，并以完整站点字节、相机函数体及上下文签名拒绝未知修改。相应 ABI、地址和各模块验证路径见同日各专题笔记。

未运行完整 Windows 游戏、真实 GPU 或双机联机；不能将编译及受控检查称为视觉或联机验收。超武栏保留防御页；PCX-only 条目以文字回退。原生规划已有闭环、松Z、读档、雷达命中及 MOD 共存需要实机观察。
