# 1.0.14 — 预定面板尺寸与点击反馈

本版基于 1.0.13，仅修改预定面板展示和成功点击的本地声音反馈。

## 动态高度与半透明

原高度固定为 188 像素队列头部加屏幕能容纳的最多六行候选，空队列也会留下大量空白。现在 Layout 保存实际队列数和候选数：队列以 48 像素卡片、24 像素步长叠放，提示跟随实际队列底部；候选只占实际需要的行数。绘制、命中测试、滚动边界、窗口尺寸共用此布局。无候选时不保留候选行；超过视口容量时滚动。增删立即调整，周期采样也会更新。已有 2K 游戏到 4K 客户区换算和用户缩放继续生效。

普通 GDI 窗口加 WS_EX_LAYERED / SetLayeredWindowAttributes，整体 alpha 为 216/255。文字和图标随窗口轻微透明，既有非激活/置顶方式保留。不存在额外游戏绘制 Hook。

## 原生音效与统一入口

核对 YRpp `RulesClass::GUIBuildSound` 与 `VocClass::PlayGlobal(int,int,float,AudioController*)`，并在参考 EXE 中核对 GUIBuildSound 解析写入 RulesClass+0x18C，以及原生侧栏 0x6AAFE1..0x6AAFF8 使用该字段，以中心声像 0x2000、音量 1.0、空控制器调用 0x750920。

- 上游接口：https://github.com/Phobos-developers/YRpp/blob/master/VocClass.h
- 参考 EXE SHA256：c287d62a4d6a25b547e9339d071dd6e03adcf545699062e478aaeee38c60e89a。它是 CnCNet 修改版，不能据此声称所有平台兼容。

外部预定成功后写入同一 Shared 接口中的短时 UI 音效请求，经既有 GameRuntime 消息调度器和 Assist 游戏线程执行租约调用 `callFast`。这不是新的 DLL/Hook，也不是仿真指令通道。它不占生产命令队列、不使用 EventClass、不进入 OutList/DoList、不改变功能调度的事件预算。没有请求时不调用音频接口。

请求字段在回执前不可覆写；回执只有 Runtime 写。忙时跳过新音效，避免反馈排队。游戏侧检查对局、前台、开关、聊天及 300 ms 源时间；既有加载/菜单/对局隔离仍先于消费。回执先于可选音频调用，避免异常重复播放。检查音频入口十字节签名，第三方改写不兼容时静默跳过，保留预定功能。原生侧栏追加不发声音请求，防止双重播放。Assist 协议升级为 48，并同步映射名、双方结构大小验证和采屏观察工具。

## 验证

- Windows x86 EXE / DLL 编译，文件版本 1.0.14.0，Assist 协议 48；PE / ABI 和架构审计通过。
- 宿主实际预定代码回归：FIFO5、原生/未来建筑、父建筑取消、回执、右键/Shift、最后一项生产时面板保留、实际帧间隔。
- 2016 组队列数/候选数/分辨率/缩放组合检查尺寸与命中，另验证窗口 alpha、增删收缩和仅成功覆盖层点击请求音效。
- 28 项实际 x86 DLL 音效夹具：单机/网络模式各测即时、300 ms 边界、过期、旧局、后台、关闭、聊天、菜单、观察位、缺失规则、禁用音效、入口签名冲突、同时生产、错误线程。观察音频调用参数与只播一次；无游戏代码写入、无额外仿真事件；并发生产仍成功。
- 36 项实际 DLL 预定 Produce 构造回归，覆盖四种 Session 与生产合法性/状态边界。

夹具模拟游戏世界、Win32 和音频设备；没有实际 Windows 画面/声音、LBW 或双机网络验收。历史验证报告仅代表各自版本。原架构尚存的装车、维修、卸载规划迁移及跨功能原子快照问题不属于本版修复。
