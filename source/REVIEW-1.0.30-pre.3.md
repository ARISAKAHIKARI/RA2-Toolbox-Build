# v1.0.30-pre.3 实现与验证

基线：v1.0.30-pre.2 / 18c9d6847ddeef7a207375947b28ff0923cb3bcc。文件版本 1.0.30.2；Assist 56、Runtime 4、入口管理器 3。宿主和 Runtime 必须成套更新。

## 高刷策略（实验性）

高级与实验性页提供「仅光标 / 光标＋拖屏 / 全部」，默认仅光标，光标仍沿用光标页开关和刷新率。另两档画面目标 60–240 Hz（默认 120），以现有宿主唤醒驱动游戏线程，不增加输入 Hook、线程内游戏循环或逻辑帧推进。

- 拖屏使用原版边缘滚屏 0x692B60、右拖 0x693440、SetTacticalPosition 0x6D6000 和 GScreen::Render 0x4F4480。模式「全部」在没有相机移动时也执行合成与呈现；鼠标移出视口不阻止整幅画面绘制。
- ScrollMap 0x4A9840 的 8 字节适配器通过现有 GameEntryManager 安装；完整剩余函数体及相关入口签名匹配后才启用。速度型滚屏按墙钟经过时间折算，携带不足一像素的余量；位移型右拖保持原位移量。
- 适配器逻辑经共同 Capture 租约；租约不成立时重放被替换指令并返回原版 ScrollMap 的连续代码，避免把原版滚屏吞掉。实验绘制只在同一游戏线程、对局/显示就绪、前台且非聊天/菜单时发生。失去条件或切回仅光标后恢复，外部补丁冲突不覆盖。
- 画面目标是近似调度频率，受 Windows 定时器、消息处理、原版原生绘制、渲染器和显示器限制；现有原版绘制仍保留。没有运动插帧，也不改变单位 AI、逻辑帧计数或联机速度；因此持续重绘不等于单位动画获得同等数量的新状态。
- 新增 mode / Hz / status / draws 诊断；draws 是额外原生绘制调用次数，不能当作显示器实际 FPS。

参考原生接口：[YRpp TacticalClass](https://github.com/Phobos-developers/YRpp/blob/phobos-dev/TacticalClass.h)、[MouseClass](https://github.com/Phobos-developers/YRpp/blob/phobos-dev/MouseClass.h)、[GScreenClass](https://github.com/Phobos-developers/YRpp/blob/phobos-dev/GScreenClass.h)。两个提供的 EXE 均核对了相关磁盘入口。兰博玩的绘制入口含一个已知跳转，保留原入口调用以执行平台自己的绘制路径；其跳转目标由启动时填充，磁盘样本不含有效函数体，受控测试的渲染器替身不能证明该目标的实际绘制效果。只接受原版或此已知入口，不接受任意第三方跳转；其他启动期改写可能导致接口不兼容。

## 小地图相机边界

当可滚动轴的下限大于上限时固定到二者中点，正常尺寸保持原版夹取行为；地图尺寸恢复正常、停用会恢复原字节。仅在完整原版夹取函数匹配时安装，已有其他修复保留。参考 [CnCNet yrpp-spawner ClampTacticalPos](https://github.com/CnCNet/yrpp-spawner/blob/main/src/Misc/Bugfixes.ClampTacticalPos.cpp) 的反转边界处理；没有引入其雷达或黑边填充改动。

## 智能卸载、刷弹和躲弹

- 为当前选中的己方运输车保存短时载员观察；只有显式智能卸载命令才接续已经走出的载员。身份、载车类型、手动输入版本和时间/帧范围继续校验，超过 1500ms 或 90 帧就丢弃，聊天或关闭功能清空。
- 配置为 Ctrl+D 等组合时，不把组合中的 D 误判为取消智能卸载；原版 D 抢先卸载仍可通过短时观察恢复任务。没有全局屏蔽原版 D。
- 工程师/间谍从车中走出时可以提前占领/潜入；外部计算只放宽同一原版 Move 的坐标漂移，保留身份、任务和动画检查。部署未被观察到时等原生回执窗口（300 帧）结束才重试，已观察到但中断的部署使用原短间隔。
- 刷弹的 Stop 和恢复 Attack 保持同一有序原生队列，恢复改为下一逻辑帧，不再等待一闪而过的 Stop 状态；新开火状态直接开始下一轮。前台检测可每 4ms 采样，复用同线程观察并减少重复读取，仍受单位仲裁、规划预算和原生事件延迟约束。没有修改 ROF、Burst 或单位能力。
- 航母/无畏母体和生成子单位继续被排除。兰博玩磁盘样本的连射重置存在启动期转移，受控测试不能证实完整游戏中的刷弹增益。
- 躲弹允许实际锁定己方的己方/盟友飞机攻击触发，用于强制攻击自测；治疗武器和未锁定攻击不纳入。碾压仍只看敌方。仍不是地面弹道或全弹种预测。

## 科技、地图和掉线反馈

保留原有科技全开与地图显示功能，没有新增平台或联机禁用。上传日志覆盖旧的 1.0.20.0 / 1.0.30.0，未包含本版；最后记录的联机过程先启用地图显示、后启用科技，继续记录若干帧后脱离，没有记录异常地址或可确定原因。未观察到工具下令计数增加，不能据此证明无不同步，也不能把掉线直接归因于某一项功能。

两个磁盘样本的科技侧栏接口相同，遮罩相关启动期入口不同。新增科技/地图开关状态及战术、高刷诊断，便于下一次实际复测；这不构成对战网掉线的修复结论。原始用户日志不随源码或发布包上传。

## 验证边界

共 542 项受控用例通过，结果见 verification/pre3/summary.json。最后一次代码调整仅加入兰博玩已知绘制入口签名：此前战术、相机和科技回归针对候选 DLL，最终发布 DLL 另跑两平台 68 项高刷回归和 PE/ABI 校验；每个报告标明实际测试的 DLL 哈希，不能将此前用例误认为全部针对最终二进制重跑。执行真实 x86 GameRuntime 和部分原版 ScrollMap / SetTacticalPosition / Clamp 代码；Win32、鼠标、边缘/右拖输入源、渲染器、单位/地图对象使用受控替身。测试检查额外绘制不推进原生逻辑帧、无下令事件及单位状态改动，不能替代真实渲染器的所有副作用检查。

没有进行 Windows 完整游戏、显示器帧率测量、平台启动后端到端刷弹或双机联机测试。因此本版保持预发布；界面注明实验性，默认不启用额外画面刷新。
