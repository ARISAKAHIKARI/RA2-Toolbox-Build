RA2 Toolbox 1.0.44-pre.4 — 控制全部直接放行优化预览版

使用方法
1. 关闭工具箱并退出游戏，避免旧版 Runtime 留在游戏进程中。
2. 将 Update 压缩包全部解压覆盖到现有 1.0.43 / 1.0.44 系列完整版目录。
3. 保留原有资源、profiles、engine、runtime、cache 和个人设置。
4. 主程序、GameRuntime.dll 与 GameRuntimeHost32.exe 必须配套更新，然后启动工具箱。

本轮变化
• 硬件“控制全部”的普通权限查询直接转入游戏原生的返回 true 分支。
  两处所属方查询仍转入原生严格比较，保留原 CALL、返回地址和栈平衡。
• 回调不再逐次读取世界十个字段，也不再查询目标 House 数组、编号或 UID。
  开关、停止、故障、已发布许可和断点策略版本仍在每次命中时检查。
  未获许可时继续游戏原有判断，不强制游戏返回 false。
• 世界资格在正常维护及启用阶段检查后发布。死亡、观察者、暂停、换局等
  变化由下一次维护撤销许可；不再声称这些字段在每次异常内即时检查。
  维护由游戏线程消息/现有工作入口驱动，没有固定毫秒延迟保证。
• 四个物理断点槽的固定控制掩码改为常量表，减少每次分类的重复位移计算。
• 继承 pre.3 的科技候选预计算和 pre.2 的共享世界样本。

验证边界
本轮减少本工具在一次硬件异常内的工作，断点位置、实际触发次数和四槽预算
保持不变。没有自动切换到代码补丁，没有添加修改 Owner 或事件所属方的逻辑。
系统异常派发和恢复成本仍在。受控回归、Windows 目标构建和静态 PE 检查
不能代替真实 Windows 游戏、帧率或联机验收；不提供实机加速百分比。
