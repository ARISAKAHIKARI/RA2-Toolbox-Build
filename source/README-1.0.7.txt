RA2 Toolbox 1.0.7 测试版（文件版本 1.0.7.0 / Assist 协议 45）

升级前退出游戏并关闭工具箱；EXE 和 GameRuntime.dll 必须配套更新。
Update 包覆盖已有 1.0.2 或更新完整目录。Windows 包含完整运行资源。
保留 Assist.ini、settings.ini 和 cache/unit-icons。

本轮整体回归修复：
1. 选中载具逃生：事件队列满或本帧额度用完时，仍观察部署动画、移动和部署完成。不会漏掉动画中断后的重试；首次尝试仍按乘员独立进行。
2. 地图绘制测试、任意建造、原生飞机路径点：菜单/对话框/战术视图未激活时，原生回调立即回落原版，不等待下一次宿主采样。
3. 关闭工具/断开桥接时，在同一有效对局及游戏线程中恢复绘制入口后请求一次原版重绘，避免只恢复代码却未刷新缓存画面；故障、暂停或换局期间不调用旧世界。
4. 战术面板：科技目录与新增 Hook 风险说明不再重叠；所有新选项仍即时生效并自动保存。
5. 截图诊断工具使用协议 45 和新的 requestTick 偏移；绘制测试状态纳入自动日志。

仍只有 GameRuntime.dll 负责游戏侧操作；没有新增 Hook 位置、调度线程或 OutList 改写。
地图绘制测试默认关闭，只去遮罩，不解除对象/目标判断；与旧地图全开许可互斥。建议新对局单独测试。
任意建造和原生飞机路径点默认关闭，仍标注联机危险。智能卸载、科技全开、敌方建筑变卖仍停用。

验证包含实际 x86 DLL / 原版事件构造器模拟、双端按帧模型、算法压力和 UI 几何/设置测试。
未运行真实 Windows 游戏、LBW、双机平台联机、像素截图或端到端延迟测试，不能据此承诺联机不掉线。
完整审视报告和可复现测试在 GitHub 源码仓库；Release 附件只放运行程序与资源。
