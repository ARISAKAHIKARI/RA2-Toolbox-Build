# v1.0.30-pre.7 界面整理与验证

基线：v1.0.30-pre.6 / 74f13dac5e6a0be1098d4b4987b722c7ea502ba9。文件版本 1.0.30.6，Assist 58、Runtime 4、入口管理器 3。

## 入口调整

高刷光标页直接显示「高刷范围」三档选择、画面目标 60–240 Hz 和补充绘制频率 / 最长间隔。光标目标帧率与画面目标分开标注。展开高级设置时，新区域仍在普通页面中；高级区域整体下移避免重叠。

单位统计页使用左右两栏，左侧保留统计显示控制，右侧为单位状态：敌方提示、载具载员与容量、未选中载具、铁幕 / 力场、冷冻、蜘蛛及火力 / 防御 / 速度强化。状态文字缩放和信息显示刷新率也迁入右栏。原战术助手中的这些入口隐藏，避免重复设置；原始 INI 键、默认值和保存逻辑沿用。

统一宿主提供带锁的设置快照，控制句柄通过原子变量登记。新入口只异步投递更改到原设置所属 UI 线程；接收端校验 11 项设置的范围，更新原控制后调用现有通知处理器。没有让页面线程直接访问另一个页面的控件、额外写配置或游戏映射。初始化未完成时控件禁用；相同状态不重复发送刷新通知。数字输入未完成时保留运行值，失去焦点后恢复有效值。

此次为入口与表现调整，原显示采样、执行模块和功能总开关关系保持不变。

## 预定面板

移除「尚无预定 / 点击建造图标追加」「右键退顶层 / Shift 清空」等常驻说明，以及普通加入 / 取消的文字通知。成功操作仍沿用原声音反馈，失败或队列满等异常保留必要说明。

暗蓝背景、青色选中标签、圆角卡片与悬停描边替代旧色块；空队列使用加号图形，五个容量点表示预定数量，等待提交使用三个点。保留单位图标、单位名称和队列序号；原生侧栏角标仅显示序号。透明度调整为 236/255，删去 20 游戏像素高的提示行。绘制、堆叠命中与候选命中继续共用 Layout，缩放与小分辨率适配由原几何流程处理。

所有内容先在复用缓冲区完整绘制后呈现，背景覆盖每个像素，避免圆角之外留下未初始化内容。鼠标悬停仅使面板失效重绘，不新增游戏命令或刷新计时器。

## 验证与限制

见 verification/pre7/summary.json：

- 11 项设置的两端合法值、越界值、未就绪拒绝及原控件通知路由；10,000 次跨线程状态发布验证读取一致性和不变状态合并。
- 原设置处理器的立即生效、自动保存及两个标志开关独立持久化回归。
- 预定宿主保留 FIFO、取消、队列提交与单次确认；2016 组内容 / 缩放 / 视口组合验证面板增长与点击命中。
- 绘制模型运行 1000 次不变刷新，确认整帧呈现、缓冲复用；另覆盖 36 种缩放 / 视口 / 队列组合及 GDI 资源分配失败。
- 最终 x86 EXE / DLL 的版本、依赖、导出、协议和清单检查；新增界面代码只在宿主包含图内。

绘制与控件消息测试使用可移植替身，没有执行 Windows 窗口系统、真实字体栅格化、完整游戏或双机联机。没有新增游戏 Hook、协议字段或同步命令。
