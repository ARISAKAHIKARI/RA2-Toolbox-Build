# v1.0.36 实现与验证

## 改动

五大主分类：画面设置、单位统计、战术控制、战场信息、实验功能。沿用三个模块线程，战术模块内部切换三个页面；跨模块显示设置通过原有消息总线保存。说明使用悬停提示。旧设置键保持兼容，新增 PassengerBubbles、DangerPassengers、Magnetron.AutoDrop，默认分别为开、关、关。

恢复步兵原生规划事件且保留执行端判定；修正飞机地面坐标及路线保持；空坦克碉堡使用 Move；磁电确认开火后继续轮换，自动摔落独立开关通过 Idle 事件请求释放。敌方载员气泡、小地图平滑、蜘蛛/强化标志、红黄队列提醒均为只读显示。新功能不增加游戏代码补丁或私有事件通道。

Assist 协议 61，包含 20 项独立功能类型清单；EXE 与 DLL 大小/协议/共享映射命名一致。版本资源及应用清单均为 1.0.36.0。Runtime 传输协议 4、入口管理器 API 3 保持兼容。

## 验证

- 两份私有 EXE 的受控 x86 执行：步兵预检边界、原版路径点追加与提交、飞机点击与高度、原生 C4 到达/计时、碉堡事件和容量竞争、磁电 Idle 队列与重新验证。
- 磁电摔落分别验证工具箱与 Runtime 计算，开关独立开启、释放后去重、桥面/关闭/目标变化/类型清单变化时拒绝旧请求。
- 采集字节的新平台启动、ABI、模块重定位及未知变更拒绝；IFV 射程外追击回归。
- 纯逻辑：磁电轮换、暂停/正计时 rearm、单目标重试；飞机多点、跨采样到达、返航重试、暂时拥塞、无进展终止；载员状态和损坏链；四类队列状态。
- UI 实际构造代码的几何检查、独立页面滚动/DPI 尺寸、13 项跨面板设置路由、新开关保存、图标格内范围、小地图平滑与黑幕边界、架构所有权及 PE/导入/版本校验。
- 完整运行包检查压缩包安全路径、CRC、资源、三套配置、离线环境和逐文件 SHA-256；发布后下载核对全部三个附件。

具体输入哈希和测试结果见 `verification/review-136/summary.json` 与对应 JSON/日志。生成器测试使用 Win32/世界/输入桩，不运行完整实机寻路与画面；磁电 Stop 入队不等于落地必杀，不宣称双机同步已验证。
