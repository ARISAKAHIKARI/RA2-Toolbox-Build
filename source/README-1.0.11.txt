RA2 Toolbox 1.0.11 Beta / 文件版本 1.0.11.0 / Assist 协议 46

本版新增三个独立缩放设置，均为 50–250%，默认 100%，输入有效数值立即生效并自动保存。

1. 单位统计 → 显示缩放 %：缩放玩家面板、图标、数量和名称。
2. 战术助手 → 显示与配置 → 载员 / 铁幕文字缩放 %：缩放载员、铁幕 / 力场、冻结倒计时及高级移动标记，仍跟随原单位位置。
3. 战术助手 → 显示与配置 → 建筑预定面板缩放 %：补充面板的文字、图标、预定编号和点击区域一起缩放。

自动游戏分辨率 / 客户区适配仍然生效，以上为额外缩放。例如 2560×1440 游戏画面映射到 3840×2160 客户区时，100% 已包含 1.5 倍适配。面板在空间不足时限制实际放大比例，保存的设置不变。原生侧栏尺寸不被预定面板缩放修改。
配置位置：settings.ini [overlay] scalePercent；Assist.ini [Display] LabelScalePercent、ConstructionScalePercent。

继承 1.0.10 的预定保持、覆盖层分辨率适配和智能卸载修复。本版不新增游戏 Hook，不改原版任务或单位能力。GameRuntime.dll 的 .text 与 1.0.10 一致，DLL 版本资源更新。
此前默认关闭的实验功能仍保留原有限制和风险；UI 缩放不需要启用它们。路径追加研究并不等于已验证普通步兵可以爆破、占领或潜入，本版未据此开放新功能。

更新：关闭工具和游戏，EXE / DLL 成套替换；保留原配置和 cache。Windows.zip 是完整运行包；Update.zip 用于覆盖已有 1.0.2 或更新的完整目录。源码与说明在 GitHub 仓库 source/，Release 附件只含运行文件和说明。

验证：编译、PE / 协议 / 依赖核对通过；设置处理、预定 Host 的 7 档缩放 × 6 组分辨率及点击区域、226 个战术控件的布局检查通过。检查使用可移植夹具，尚未进行真实 Windows 像素显示、LBW 或双机联机验证。
