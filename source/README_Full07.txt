RA2 Toolbox 0.7.20 Full

本版基于 0.7.19。设置即时生效并自动保存。

新增：
1. 单位统计图标与色盘后台缓存到 cache/unit-icons；按游戏路径及资源指纹隔离，退出后仍可复用。读取到实际图标后校正，坏缓存忽略。首次从未读到过的图标仍需等待游戏载入。绘制位图内存复用。
2. 战术面板“自定义矿车类型”“自定义矿场类型”：未勾选按原版自动识别；勾选后仅使用 ID 清单，逗号分隔，空清单表示不参与。支持离线配置和自动保存。示例矿车 HARV,CMIN，矿场 GAREFN,NAREFN。
   MOD 可填写自己的类型 ID。矿车仍需有储矿容量；目标矿场须在矿车原有 Dock 清单内，不改原版类型字段。这里配置的是自动倒矿，空闲矿车定位仍按原版分类。
3. “允许维修不可维修的建筑”默认关闭。关闭时按原版 ClickRepairable 过滤；开启允许己方非标准建筑，仍检查归属、血量、维修状态和去重。维修快捷键共用许可。关闭后未提交请求被过滤，已入队的维修事件不撤回。

安装：先退出游戏及旧工具箱，再整体解压并运行 RA2Toolbox.exe。EXE 和 GameRuntime.dll 必须同版（Assist 协议 40）。可迁移旧 Assist.ini 与 settings.ini；需要保留已缓存图标时一并迁移 cache/unit-icons。

地图全开保留实验性许可，默认关闭；单位统计支持“常驻显示（不依赖 Tab）”、Ctrl+Alt+H 及显隐按钮。保留十项独立鼠标按钮、空组合键、组合选兵和仅选中载具逃生；没有新增自定义优先级。
科技全开、随处建造与敌方建筑变卖继续停用。
所有游戏指令经唯一 GameRuntime 管理器。没有新增功能级 Hook、游戏代码改写或直接修改矿车/建筑类型属性。

开发文档见 docs/FULL-0.7-Architecture-and-Features.html、docs/TEST-REPORT.html。运行分发包不附项目源码和测试材料；engine/runtime 的 Python 文件是必要运行依赖。
本版通过便携及实际 DLL 模型测试；尚未进行真实 Windows 绘制、LBW 和双人游戏联机测试。
