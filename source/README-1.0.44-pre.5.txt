RA2 Toolbox 1.0.44-pre.5 — 模块性能与正确性审查修复预览版

使用方法
1. 关闭工具箱并退出游戏，避免旧版 Runtime 留在游戏进程中。
2. 将 Update 压缩包全部解压覆盖到现有 1.0.43 / 1.0.44 系列完整版目录。
3. 保留原有资源、profiles、engine、runtime、cache 和个人设置。
4. 主程序、GameRuntime.dll 与 GameRuntimeHost32.exe 必须配套更新，然后启动工具箱。

本轮五类修复
• 反向躲弹：已处理且身份匹配的弹体，在全单位目标收集之前跳过；
  保留首次处理、失败重试、身份校验、既有持续任务和原生命令提交规则。
• 共享世界样本：消费者停止使用的原始页请求会到期清理；心跳超时后
  停止旧请求的额外采集和发布。相同页集合不再重复改写需求版本。
  暂停帧恢复订阅可重新发布已有封闭样本，重复唤醒不会重复导出。
• 地形渲染：同一不可变 Token、同一区域且缓存完整时复用已验证结果；
  新样本、区域、资源、光照和精度变化仍触发需要的检查。
• 调色缓存：缓存绑定实际封闭读取 Token，避免同帧不同样本误用旧表；
  缺页继续按不完整处理，不用旧表掩盖新样本的读取失败。
• 设置保存：完整 INI 分组纳入异步写入、失败提示、重试及关闭门控；
  修复分组保存失败未被统一状态捕获，以及失败重试覆盖后续键值的问题。

继承 pre.4 的“控制全部”直接许可分流、pre.3 的科技候选预计算、
pre.2 的共享世界样本；本轮没有更换硬件断点方案或扩大物理槽数量。

验证边界
专项对照执行使用真实生产函数或类及受控系统边界。完成 Windows 目标
构建、静态 PE 检查和配套打包；未在真实 Windows 游戏、GPU 或多人
环境中执行，不提供实机 FPS、异常延迟或磁盘延迟改善百分比。
完整功能审查记录、复现条件和未确认的性能候选见 Verification 包。
