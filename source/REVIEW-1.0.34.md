# 1.0.34：新平台识别与 Hook 诊断

Windows 文件版本 1.0.34.0；EXE 与 DLL 成套替换，Assist 60 / Runtime 4 / 管理器 3 协议不变。保留 1.0.33 控制全部及其他功能。

随机名称候选必须再核对所提供的游戏文件指纹，不能只凭十六进制名称或窗口标题接受进程。光标改用与统计、辅助相同的发现入口。新增缓存隔离、子窗口发现和多阶段 Hook 安装日志。

用户已确认该平台只读功能可用、Hook 功能未生效。本版本提供名称兼容和定位信息，**尚未确认修复 Hook 失效**。不改变注入方式，不放宽原生主窗口、游戏线程、模块归属或补丁签名检查。

测试覆盖实际附件的文件指纹和受控扫描/Hook 安装；该附件上 56 项控制/科技 Runtime 检查通过。Windows 编译、PE/ABI/版本/导入与架构检查通过，未做平台实机或联机验证。证据见 `verification/review-134/` 和研究索引。

使用：退出游戏和工具箱，覆盖两个运行文件后重开；进对局后触发一个此前无效的功能，等待约 10 秒，再回传工具箱目录的 `logs/Runtime.log`。如目录不可写，日志位于 `%LOCALAPPDATA%/RA2Toolbox/logs/Runtime.log`。
