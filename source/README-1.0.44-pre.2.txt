RA2 Toolbox 1.0.44-pre.2 — 性能修复预览版

使用方法
1. 关闭工具箱并退出游戏，避免旧版 Runtime 仍留在游戏进程中。
2. 将 Update 压缩包全部解压覆盖到现有 1.0.43 / 1.0.44-pre.1 完整版目录。
3. 保留原有 assets、profiles、engine、runtime、cache 和个人设置，再启动 RA2Toolbox.exe。
4. 本包同时更新 x64 Host、x86 GameRuntime 和 x86 broker；不要只替换其中一个文件。

主要变化
• 战术计算、主屏、小地图、副相机、战术标签及相关界面共用 Runtime 发布的原始世界样本。
  同一个已观察到的逻辑帧不再因为另一个消费者缺页而重新读取世界。
• 原始数据采集后封口；缺少的字段登记下一帧需求。数据不完整时保留稳定输出或等待重试。
• 原生合法性查询、最终身份/权限/手动指令检查和实际下令继续使用当前状态。
• 暂停时仍能更新选择、鼠标、镜头等界面输入；复用世界样本时不改写原始采集时间。
• 共享数据缓冲区按实际页数增长，避免小需求也固定分配最大容量。
• 硬件断点先区分本方和外部异常，减少无关异常进入工具清理框架的工作。

诊断
启用既有诊断日志后，每秒记录 hardware-performance 和 world-sampling。
前者报告本方硬件异常/控制回调次数、观察窗口和维护计数；后者报告最近原始样本的页数、
实际读次数、字节数、成员表数和失败次数。它们不是实际游戏 FPS。

验证边界
此版执行了生产代码的合成内存、Win32 边界、缺页/生命周期/发布交错回归，并完成 Windows
目标交叉编译与 PE/跨位 ABI 检查。没有将这些结果作为 Windows 实机、GPU 画面、游戏帧率或
联机验证。每次硬件执行断点异常本身仍有系统开销；新诊断可用于观察实际命中频率。

现有消息调度频率保留。一次采集对应一个实际观察到且获准处理的逻辑帧，不表示调度器已经
证明覆盖了所有模拟帧。暂停时新开启的功能若需要尚未采到的世界字段，将等下一逻辑帧。
