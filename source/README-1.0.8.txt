RA2 Toolbox 1.0.8 测试版（文件版本 1.0.8.0 / Assist 协议 45）

本次修改：
1. 建造预定覆盖层按游戏内部分辨率与游戏窗口客户区换算，图标、字体、间距和鼠标命中区域一起缩放。记录 game/client/panel 尺寸到自动日志。RA2MD.INI 不作为正在运行画面的唯一依据。
2. 建筑、防御分别最多预定 5 项，显示 1–5 顺序编号；同一建筑可重复加入。
3. 没有电厂但正在造电厂时，兵营可以显示为灰色可预定项；也支持依次预定的前置链。修复 Required/ForbiddenHouses 的 -1 哨兵值、父国家和偷科技标志读取。
4. 左键图标加入；右键编号取消该项及后续项，右键图标取消最后一次同类预定及后续项。取消当前生产建筑，会自动取消后续预定。已交给游戏的第一项需等原生生产出现后按原版方式取消。
5. 当前建筑放下、工厂空闲且原版 CanBuild 与原生图标均确认可造后，通过 GameRuntime 构造生产指令。保留原版合法性和联机事件流程。
6. 队列停工提醒仅建筑和载具栏闪烁；读取游戏实际加载的 TAB SHP、按钮位置和调色板，在外部覆盖层按原图形换色。防御与步兵栏不闪烁；恢复生产停止提醒。

升级：退出游戏并关闭工具，配套替换 RA2Toolbox.exe / GameRuntime.dll，保留配置和 cache。
Windows.zip 为完整运行包；已有 1.0.2 或更新完整目录可使用 Update.zip。
本次没有增加 Hook 位置、私有入口或修改 Prerequisite；源码和测试位于 GitHub 仓库，发布附件仅运行文件。
已做模拟与静态验证，尚未在真实 Windows、兰博玩重绘环境或双机平台联机中验证。若仍错位，请提供截图和 logs 中的 Construction geometry 记录。
