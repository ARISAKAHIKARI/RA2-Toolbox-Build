RA2 Toolbox 1.0.12 Beta
文件版本 1.0.12.0，Assist 协议 46。

修复高级进驻：坦克分散进入坦克碉堡，以及车辆/船只分配到维修设施。
- 空联络槽不再被误判为占用。
- 碉堡每座一辆合法坦克；维修设施按泊位分配，不再扣除运输体积。
- 正在前往维修的单位计入预留，联络占位与在途状态不会重复计算。
- 入堡完成根据坦克和碉堡的双向关联确认。
- 运输载具仍按乘员体积计容量；驻军建筑仍按人数计容量。

使用：选中单位，使用高级进驻配置的键盘键和鼠标键点击目标，
工具在点击时屏幕内的同类设施间分配。仍须原版允许该单位进入/维修；
单位列表过滤设置仍然生效。设置为无键盘快捷键时，只按配置鼠标键。

关闭游戏与工具后，成套替换 RA2Toolbox.exe 和 GameRuntime.dll。
保留已有配置与 cache。Update.zip 用于已有 1.0.2 或更新完整目录；
Windows.zip 是完整运行包。继承 1.0.11 的三项独立覆盖层缩放。

源码与报告在 GitHub source/；Release 附件仅包含运行文件和说明。
本轮编译、PE/协议检查、外部规划及 20 个 Runtime 夹具测试通过。
夹具不等于真实游戏寻路、实际维修完成或双机联机测试。
