# RA2 Toolbox 1.0.38-pre.9 更新说明

本轮改进小地图边界、驻军建筑外观和缩放画质，并补充维修扳手与抛射体显示。

## 本次更新

- 小地图下边界：对齐可绘制范围与画布裁剪，处理底部异常边缘。
- 民房驻军：进驻和离开后更新建筑外观。
- 缩放画质：先按原始尺寸合成场景，再在显示时统一缩放。
- 战场效果：补充维修扳手动画和可见抛射体。
- 发布说明改用简体中文，补齐项目首页、版本历史和第三方鸣谢。

## 下载与更新

更新包只包含 RA2Toolbox.exe 和 GameRuntime.dll。请退出游戏与工具箱后成套替换，保留原 INI、assets 和 cache。源代码另包提供，包含构建脚本、许可和研究文档。

具体构建来源和文件校验值见 release-manifest.json。具体实现及验证范围见[研究索引](../source/research/INDEX.md)。
