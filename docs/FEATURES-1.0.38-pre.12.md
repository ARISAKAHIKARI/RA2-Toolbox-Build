# RA2 Toolbox 1.0.38-pre.12

本版调整生产预定的单位队列提交、统一覆盖层的战场状态读取，并把新配置的小地图缩放默认值设为 25%。

## 本次更新

- 步兵队列及载具队列（含飞机、舰船）各可预定最多 30 项。可建造后逐帧向原生生产队列续送，成功提交一项便继续处理下一项，无需等待单位造完；原生队列满时保留未提交的项目。建筑与防御各保留 5 项预定，按前置完成顺序逐项提交。
- 新配置的小地图缩放默认 25%，设置范围保持 10%～200%；已有配置继续使用保存的缩放值。
- 小地图在一次单位读取暂时失败、采样过期或绘制容量重试时保留同一场战局的上一帧，修复单位每隔几秒闪烁；单位确实离场时仍会从地图移除。
- 实景小地图按游戏雷达的原始画布裁切地格，修复南缘高地多出几行的问题；无黑幕预览遵守游戏实时可用范围。缺失地块类型时也不再补画推测色菱形。
- 小地图与跟踪窗复用主显示周期已验证的战场状态；菜单、聊天和对局切换时同步处理可见性。
- 部分不可读的内存页在一个采样周期只尝试一次整页读取，其余字段直接读取；下一周期重新尝试整页。
- 单位统计的画布在 GDI 创建或选择失败时完整清理已分配对象，尺寸变化时正确释放旧对象。
- 左侧总开关和单位统计暂停按钮明确标示所控制的游戏内显示，与副屏窗口的独立开关相对应。

## 使用

在“战术控制”开启生产预定，在建造侧栏或预定面板添加项目。小地图缩放可在“战场信息”中设置为 10%～200%，新配置默认 25%。

## 下载与更新

更新包包含配套的 RA2Toolbox.exe 和 GameRuntime.dll。退出游戏和工具箱后成套替换，保留现有 INI、assets 和 cache。源码另包提供；构建信息和校验值见 release-manifest.json。
