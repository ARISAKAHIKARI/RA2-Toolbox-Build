# 敌方位置标记 · 1.0.1

在战术面板的显示设置勾选 **敌方位置标记（包含未揭示区域）**。默认关闭，修改立即生效并自动保存；配置位置为 `Assist.ini` 的 `[Display] EnemyMarkers=1`。

当前战场画面内的敌方单位和建筑按玩家颜色显示位置符号、玩家编号和类型名称。建筑使用方框，其他单位使用菱形；不显示己方、盟友、中立或已进入运输工具的乘员。不要求对象所在区域已经揭示，只显示当前游戏内存中已存在、布局兼容且状态有效的对象。

## 刷新与显示

标记和载员标签共用原有 FPS 设置（5–500）、采样时钟、`visual::Motion` 插值、绘制窗口和 `UpdateLayeredWindow`。同一逻辑帧内也重新读取坐标，不增加第二个定时器或绘制线程。

既有世界对象遍历同时收集敌方对象；逻辑帧、选择或视图变化按原有规则重新遍历，其间复核缓存对象身份和实时位置。类型名称按类型缓存，文字位图按类型与玩家复用。最多保存 2048 个当前视图标记，超出部分本次不显示。场景变化的世界遍历和同帧坐标更新不是相同工作量；设置的目标刷新率也不代表所有机器都能达到该帧率。

只在当前战场视口内绘制，裁剪到战场边界，避免覆盖侧栏。菜单、失焦、游戏/读取未就绪、跨局和数据过期时隐藏。发布采样前重新读取当前帧、玩家、镜头和显示状态，发现变化则丢弃这次标记，在后续有效采样恢复。

## 实现路径

`ReadSession → SharedReadView → TacticalSampler → visual::Motion → 现有覆盖层`

这是宿主端只读展示功能，没有新增 GameRuntime 请求、共享协议字段、游戏函数调用或 Hook。功能不修改战争迷雾，不调用地图揭示，不写游戏状态或提交游戏事件；原有地图全开仍是独立开关。

| 文件 | 职责 |
|---|---|
| `external_reader/source/enemy_markers.h` | 宿主标记快照、容量和新鲜度检查 |
| `external_reader/source/tactical_sampler.h` | 从统一对象遍历筛选、投影和同帧复核敌方位置 |
| `external_reader/source/shared_reader.h` | 发布前通过统一读取会话执行不命中缓存的复核读取 |
| `assist/source/main.cpp` | 共用采样、插值与覆盖层绘制；文字位图缓存 |
| `assist/source/extra_controls.h` | 同一显示区域中的开关和说明 |
| `assist/source/auto_settings_ui.h`、`extra_settings_io.h` | 即时应用、自动保存和加载 |

## 已验证范围

生产采样器与插值代码的便携内存模型覆盖敌我/中立识别、四类对象、同帧移动、结盟与归属变化、死亡/离图/运输状态、对象身份复用、菜单及暂停恢复、读取失败/重连、视口/侧栏边界、跨局/过期、2048 上限与损坏数组。

1000 次、目标间隔 2 ms 的调度模型验证敌方标记与载员标签在同样输入下的插值坐标一致，并检查世界枚举没有退化到每次显示采样执行。生产绘制函数在 GDI 记录模型中检查符号、坐标、颜色、文字处理与位图复用；实际设置处理器模型检查默认关闭、即时生效和保存/重载。

这些测试没有运行真实 Windows 游戏画面、LBW 或平台联机，也不提供实测 FPS、截图正确性或输入延迟结论。完整证据见 `verification/validation-single.log` 与 `docs/TEST-REPORT.html`。
