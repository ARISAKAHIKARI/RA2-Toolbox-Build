# 1.0.46.4 控制台界面整理

界面版本继续显示 1.0.46，Windows 文件版本为 1.0.46.4。

## 交互与布局

- 按钮、输入框、字号、间距和状态色使用统一样式；主操作、普通操作、危险操作通过原生控件元数据明确区分。
- 视频选项按渲染与效果、副相机、小地图、生产提醒、战场提示分组。多个独立主开关的分组使用独立标题，宽窗口分两列，窄窗口回到一列；单一主开关仍与标题相邻。
- 参数组可收起，主要功能开关保留可用。高级光标、进程连接和 Hook 探测补齐折叠信息；进程连接和探测工具初始展开，保留操作上下文。
- 错误摘要放在参数区域外，收起参数后仍可见；错误恢复保留用户当前折叠选择。
- 搜索先展开匹配结果，随后允许手动或批量收起。改变查询会重新显示匹配项，退出搜索恢复原页面折叠偏好。
- 按钮自身已有相同文字时隐藏重复标签；即时自毁操作明确显示“立即自毁”。

## 验证与交付

使用现有控制台核心、调试页核心、两套完整 Chromium 浏览器回归、portable C++ 模型、生产元数据夹具、Windows 目标编译和 Host 合约检查。浏览器在 Linux 使用官方 Chrome for Testing 151.0.7922.34 headless-shell 的单进程模式；原生元数据夹具使用受控 Win32 类型与映射。以上与原生 Windows WebView2、实机游戏、物理 GPU 和多人联机验收分别记录。

完整 x64 主程序、x86 Runtime、x86 Broker 按同一冻结源码重新构建，保持既有协议配对。`package_ui_revision.py` 验证本次 UI 日志与源码、远端完整 Git 树、构建来源和每个 ZIP 成员。原始光标、主题及授权资源从固定摘要的 1.0.46.3 Full 复用，engine 文件逐字节核对；原有性能验证保留为历史证据。

Full 和 Update 保持轻量包装，用户配置与本地缓存由覆盖更新保留。修订源码以发布 manifest 中的固定提交为准。
