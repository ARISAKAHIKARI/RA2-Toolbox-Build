# 1.0.37 发布说明准备稿

状态：尚未发布。以 1.0.38-pre.1 的当前实现汇总成用户指定的 1.0.37 正式版；配置问题核验、用户预设导入和正式构建尚待完成。

## 相对 1.0.36 新增

- 六种地面队形与真实单位预览，同组选中后继续保持队形移动。
- 最多三个局部观察窗，支持目标跟踪、组内接替和点击定位。
- 防空火控提前分配与预留火力，支持导弹／全部空军和智能／平均分配。
- 地图全开、随处建造和科技解锁的直接模式，以及独立科技加强。
- 磁电全局无限吸、扩展自动摔落条件，部分功能支持独立选择解算位置。
- 更完整的单击／双击快捷键、自定义鼠标操作和显式 Sticky 实验入口。

## 已合入的修复与改进

- 快捷键连接、队形右拖与续走、坦克碉堡进驻、磁电停止后继续操作。
- 生产队列提示、预定显示、空闲飞机轮选和切屏后的覆盖层恢复。
- 地形／单位素材读取、朝向、地图光照、状态标志位置和刷新一致性。
- 铁幕光标中心、蜘蛛图标大小、副摄像机遮挡和刷新。
- 模式名称统一为受控／直接，保留经典兼容；场景高刷与视角缩放暂时置灰。

本次待完成：冷冻时间、危险载员提示等设置的重启保持检查；按用户 INI 导入预设和快捷键，所有功能首次默认关闭。

完整清单见 [FEATURES-1.0.37.md](FEATURES-1.0.37.md)。正式说明保留特性变化，不展开 bugfix 内部实现。更新包与源码包分别提供。
