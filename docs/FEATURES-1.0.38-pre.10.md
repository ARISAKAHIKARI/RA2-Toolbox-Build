# RA2 Toolbox 1.0.38-pre.10

小地图、单位统计和小窗跟踪支持在第二显示器独立显示。

## 本次更新

- 三个副屏显示开关分别保存，关闭游戏内对应显示后仍可单独使用。
- 自动选择游戏屏幕之外的显示器；支持负坐标桌面、切换游戏所在屏幕及副屏断开后的隐藏与恢复。
- 副屏统计位于左侧，小地图与跟踪小窗位于右侧；共用已有数据和素材缓存。
- 切出游戏后仍显示有效的对局信息，退出对局或读取失效后自动隐藏。

## 下载与更新

更新包包含配套的 RA2Toolbox.exe 和 GameRuntime.dll，请退出游戏和工具箱后成套替换。源码、构建脚本和许可另包提供，构建来源与校验值见 release-manifest.json。

## 使用

在“单位统计”开启“第二显示器显示单位统计”；在“战场信息”分别开启“第二显示器显示小地图”和“第二显示器显示小窗跟踪”。跟踪目标共用现有快捷键和槽位。仅连接一个显示器时，副屏窗口自动隐藏。
