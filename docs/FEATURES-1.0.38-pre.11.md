# RA2 Toolbox 1.0.38-pre.11

本版加入可拖动的副屏窗口与按原生尺寸计算的实景小地图缩放，并整理功能分类和绘制性能。

## 本次更新

- “生产预定”及其缩放移至“战术控制”的自动任务区；“自动躲弹”移至“实验功能”。左侧总开关标为“游戏内”，与独立副屏开关更容易区分。
- 自动装车模式、Shift 五连点模式、高级移动攻击优先级及 C4 鼠标键的下拉框遇到空选或越界值时保留原设置。
- 原尺寸画布按页行生成显示图像；小地图画面和镜头没有变化时，不再重复绘制主屏和副屏窗口。
- 小地图缩放范围调整为 10%～200%。实景模式 100% 对应地图原生投影尺寸，200% 对应两倍；空间不足时等比缩小以适应窗口。示意模式沿用原有比例。
- 副屏小地图可拖动顶部改变位置，拖动左上角或右下角等比调整大小；副屏统计窗口可直接拖动，副屏跟踪小窗可拖动顶部移动整组。位置和地图宽度各自保存，独立于游戏内覆盖层。
- 退出时等待显示时钟线程结束；绘图缓冲区分配失败时完整释放已创建的资源。小地图点击跳转会及时唤醒游戏线程。

## 使用

从“战术控制”设置生产预定和小地图，从“实验功能”设置自动躲弹。在各自面板独立开启副屏小地图、单位统计和跟踪小窗；可以直接拖动副屏窗口，或者在设置中输入位置。位置值 0 为左侧／顶部，10000 为右侧／底部。

## 下载与更新

更新包包含配套的 RA2Toolbox.exe 和 GameRuntime.dll。退出游戏和工具箱后成套替换，保留现有 INI、assets 和 cache。源码另包提供；构建信息和校验值见 release-manifest.json。
