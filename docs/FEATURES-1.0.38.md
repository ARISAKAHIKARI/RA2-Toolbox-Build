# RA2 Toolbox 1.0.38 功能说明

RA2 Toolbox 为《红色警戒2：尤里的复仇》提供光标、单位统计、战术控制和战场信息窗口。设置在各面板中即时保存。

| 面板 | 功能 |
| --- | --- |
| 画面设置 | 高刷光标、显示缩放与布局、信息刷新率 |
| 单位统计 | 玩家单位统计、类型图标、分栏显示及独立副屏窗口 |
| 战术控制 | 自动装车、建筑维修、矿车倒矿、智能进驻、快捷选兵、队形、路径点与生产预定 |
| 战场信息 | 载员与危险乘员提示、铁幕及超时空计时、生产提醒、示意／实景小地图与最多三个跟踪小窗 |
| 实验功能 | 地图显示模式、科技生产方案、自动躲弹及扩展建筑指令 |

## 小地图与跟踪

- 小地图可切换示意和实景模式。实景先按原始尺寸绘制，再整体缩放；100% 对应地图原生投影尺寸。缩放范围 5%～200%，新配置默认 10%，现有配置沿用保存值。
- 黑幕遵循工具箱现有选项；半透明模式下小地图不绘制黑幕。原生模式根据实时邻格状态选择 SHROUD／FOG 边缘图像，在地形和单位完成后按平面坐标绘制。地图按原始雷达画布裁切，右、下边缘补平面底色，无黑幕预览的详细地形遵守实时可用范围。
- 小地图的单位采样短暂失败时保留同一场战局的上一帧；单位确实离场时从地图移除。
- 跟踪小窗可跟随三个目标。步兵进入建筑或载具后继续跟随，离开后跟回原步兵；镜头在地图边缘限制取景位置。
- 实景画面包含矿石／地形图案变体、建筑组成和驻军状态、维修扳手及可见抛射体。

## 第二显示器

小地图、单位统计和跟踪小窗分别在各自面板设置副屏开关，独立于游戏内覆盖层。副屏窗口可拖动，小地图可拖动角落等比调整大小；位置和地图宽度各自保存。副屏自动选择游戏屏幕之外的显示器，并随显示器切换与断开调整可见性。

## 生产预定

步兵和载具（含飞机、舰船）队列各最多 30 项。项目可建造后逐帧向游戏队列提交，队列满时保留其余预定。建筑与防御各最多 5 项，依完成和摆放次序提交。

## 安装与源码

从[1.0.38 发布页](https://github.com/ARISAKAHIKARI/RA2-Toolbox-Build/releases/tag/v1.0.38)下载更新包。退出游戏和工具箱，成套替换 `RA2Toolbox.exe` 和 `GameRuntime.dll`；保留 INI、assets 与 cache。发布页提供源码包和 `release-manifest.json` 校验信息。
