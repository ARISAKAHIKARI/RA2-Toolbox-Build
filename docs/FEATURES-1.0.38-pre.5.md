# RA2 Toolbox 1.0.38-pre.5 完整特性树

默认参数和可配置快捷键采用用户提供的 Assist(1).ini，所有功能开关首次默认关闭。之后修改会自动保存，重启继续保留；更新时不覆盖已有配置。

## 控制台与通用设置

- 画面设置、单位统计、战术控制、战场信息、实验功能五类面板。
- 画面刷新、单位统计、战术与信息三个模块独立启停。
- 设置即时生效与自动保存；数值范围检查、滚动布局、DPI 适配、悬停说明与功能定位。
- 可配置快捷键：普通组合、单击／双击、按住；键鼠组合可选择中键、侧键、左／右键，留空按住键可仅用鼠标。
- 同键多功能选择；同一键循环切换队形；组合选兵和科技清单离线保留。
- 游戏发现、重新连接、运行状态、自动日志与诊断；共用入口支持 gamemd-ares.exe 和 gamemd-spawn.exe。
- 各自动功能独立的单位类型清单；部分功能可选择游戏内或工具箱解算，下一局生效。

## 画面设置

- 高刷光标：目标刷新率、跟随显示器、最高 500 FPS、平滑补帧与自适应。
- 光标显示与原光标处理：保留／隐藏原光标、外置显示、游戏内显示及菜单保护。
- 光标素材：导入 SHA、动画分组、离线预处理、样式切换与预览。
- 光标校准：自动／手动缩放、纵横比、游戏与屏幕分辨率、DPI 模式、热点偏移、超武热点居中。
- 状态面板、自动检测及临时暂停。
- CnC-DDraw／TS-DDraw 配置与恢复。
- 地图显示：关闭、受控半透明、受控透明、原生揭示、直接模式。
- 场景拖屏高刷、全部高刷、强制高刷：入口暂时禁用；目前只开放仅光标。
- 视角缩放：入口暂时禁用。

## 单位统计与状态

- 各玩家单位数量统计；可选建筑、其他玩家，支持分页。
- Tab 按键切换、按住显示、短按切换／长按暂显；常驻显示和手动显隐。
- 统计缩放、上／左边距、游戏已解析字段／内存 INI／MIX 的建造图标与色盘读取、图标缓存、布局演示及重新连接。
- 载具载员数量／容量，可同时显示未选中载具。
- 铁幕／力场剩余时间、冷冻剩余时间。
- 蜘蛛寄生标志，火力／装甲／速度箱子强化标志。
- 敌方单位位置和名称提示；同一玩家、同一类型且两两距离不超过两格的机动单位聚类并显示数量，建筑单独显示。
- 悬停／选中敌方载具的载员气泡，危险载员常驻提示；气泡位置随覆盖层平滑更新。
- 状态文字缩放、信息刷新率；各类标识与主覆盖层共用刷新节奏。

## 战术控制

- 维修：一键／自动维修、间隔、允许维修通常不可维修建筑。
- 选兵：作战单位、空载运输载具、受损单位、空闲矿车、空闲工程师、空闲运输载具、空闲飞机。
- 组合选兵：多个类型共用快捷键，屏幕／全图选择，手动添加 ID，按当前武器选择同类。
- 自动装车：就近优先／兵种均衡、范围、类型清单。
- 智能卸载、载员自动逃生、停止所选单位的自动任务。
- 清除己方信标、喝彩、嘲讽 1–8。
- 超级武器目标选择和独立绑定。
- 高级移动攻击：额外索敌范围、检测频率、价值／伤害比例优先。
- 磁电轮换攻击、全局无限吸；手动命令接管。
- 高级进驻：载具、驻军建筑、坦克碉堡、维修厂／船厂等按原版能力分配。
- 飞机分配攻击：两种组合键、每目标数量、类型覆盖及最大数量。
- 飞机路径点：关闭、兼容、原生优先；跟随游戏按键或自定义按住键。
- 飞碟主武器攻击、出售被吸取目标、出售战车（兰博玩不支持）。
- 直接攻击移动、Shift 五连点及兼容策略。
- 地面队形：矩形、分散、圆形、扇形、正方形、空心框；拖拽预览、零拖拽提交、同组后续移动保持队形。
- 矿车自动卸矿：排队、旁格等待、手动接管、矿车／矿场清单。
- 防御建筑优先攻击工程师、间谍及爆破等渗透单位。
- 防空火控：仅导弹／全部敌方空军、智能／平均分配、提前预留、机动单位有限接敌。
- 自动躲弹（实验性）：短距离移动／原版散开。

## 战场信息

- 生产预定：每类队列 5 项、前置条件等待、取消联动、面板缩放。
- 六条生产线独立提醒：建筑、防御、步兵、载具、舰船、飞机；空闲红闪、暂停黄闪。
- 空闲飞机指示器与逐架轮选。
- 战术小地图：示意／实景两种画面，缩放最高 1000%（受游戏窗口可用空间限制），水平／垂直对齐、自定义坐标、点击／拖拽定位主视角；实景共用副相机资源与绘制管线。
- 最多三个局部观察窗：跟随悬停／选中对象、独立快捷键、危险载员自动跟踪、组内死亡后近处成员接替。
- 观察窗点击居中、独立关闭、菜单避让、覆盖层遮挡和同步刷新。
- 短暂失读和较慢的后台渲染保留同一目标最近完整画面；窗口槽位由跟踪生命周期管理，死亡接替和手动关闭不会被旧结果恢复。
- 小窗与小地图同时遵守原版地图范围及当前可视范围；地图触发扩界／缩界即时更新采样、相机限制和缓存，过小地图固定于中心。
- 真实 TMP、SHP、VXL/HVA 资源显示；按原版光源方向计算 VPL／法线光照、自发光颜色、逐像素深度、建筑 Z 图与阴影。
- 普通建筑／车辆使用原版所选的所属方或自定义色盘色调；地形色盘建筑及动画分别遵循原版的转换器和亮度来源，防止地表色调泄漏到单位。
- VXL 模型局部坐标与原版朝向对齐；光源为方向参数，SHP 沿用素材已绘制的明暗。
- 建筑附加动画按原版当前帧、Layer 和 YSort 合成，包括活动／空闲／生产／超武和损伤火焰；补充建造／出售的 Buildup SHP 和全局爆炸等瞬时动画。
- Bib 与工厂独立生产基底、屋顶底层和门按实际状态绘制；正常／受损、屋顶出厂及门计时器分别选帧，缓存跟随状态更新。
- 覆盖层统一窗口层级，小地图和副相机作为不透明面板排除世界标记。
- 覆盖层素材解码与画面合成由独立后台工作者处理；有界最新快照和换局淘汰，窗口线程接收完成画面。
- 同局隐藏／返回菜单时保留素材，调整尺寸保留已解码资源；MIX、姿态与像素缓存设有内存预算。
- 摄像机角度和固定 2:1 投影沿用原版基线，本版只限制靠近地图边界时的相机位置，没有旋转摄像机。
- 敌方索敌线、箱子位置／信息、战术文字提示、运行耗时。

## 实验功能

- 自动移动攻击（CS）和按键移动攻击（CS）。
- 磁电全局自动摔落：依据正下方目标、地形和水陆条件，独立开关及清单。
- 随处建造：受控模式／直接模式。
- 科技解锁：受控模式／经典兼容／直接模式；预置、自定义、旧式允许清单；生产与取消。
- 科技加强（实验性）：尝试开放隐藏类型，关闭时恢复本工具持有的字段修改。
- 操控其他玩家单位；保留原属方。
- 步兵强制进入建筑：保留现有路径点入口，实际能力仍由原版判定，本轮不扩展 C4。
- 显式 Sticky 驻守；联机进入仍属实验，联机退出尚未实现。
- 优先执行增强指令、原版命令兼容选择。
- 已禁用或移除：切换操控方、出售敌方建筑、视角缩放、场景高刷、强制刷弹和箱子结果 Hook。

渲染仍属预览：建造／出售已补充原版帧选取与专用素材路径；闸门、废墟及扩展 MOD 的特殊表现未全部完成实机对照。当前没有各平台游戏画面、FPS 或双机联机验证。

实验性功能不承诺所有 MOD、平台或联机稳定。既有功能列表不代表本轮已重新完成全部实机验证。
