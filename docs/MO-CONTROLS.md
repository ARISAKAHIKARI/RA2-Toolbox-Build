# 操作配置与严格无代码补丁核心

MOControls2 基于 MOControls1 `5cd90d7dde2f8de4dd1d08e0665ae8be18d05bd6` 修正；没有退回旧功能基线。沿用既有无代码补丁策略：Entry ABI4、Runtime5、Assist85；`CodeWritesAllowed=false`，安装和恢复补丁均在访问目标及调用OS前拒绝，虚表也不例外。宿主验证 `GameCodeWritePolicyInfo={1,0,0}`，旧Runtime不允许混用。

## 与现有功能共用配置结构

控制页的每项操作使用“功能开关 / 按住键 / 鼠标键”。按住键接受持续按住、组合键、双击按住；留空为纯鼠标。鼠标支持中键、侧键、左键、右键和停用。完整配置通过既有自动保存写入 Assist.ini，通过带序号的共享快照送给Runtime；Host捕获和Runtime执行读取同一策略。重复或无效绑定显示提示并拒绝冲突手势。

| 功能 | 默认按键 | 严格模式实际状态 |
| --- | --- | --- |
| 模糊下令 | Ctrl + 中键 | 已接现有事件桥，可自定义键与鼠标 |
| 区域目标分配 | Shift + 中键 | 已接现有事件桥，可自定义键与鼠标 |
| 快速占位 | 纯中键，共用队形开关 | 已接现有队形结构，可自定义键与鼠标 |
| 自定义巡逻圈 | Z + 中键 | 已接原生事件桥，可自定义；独立于物理Z；协调游戏实际路径点键 |
| 飞机路径点 | 沿用路径点按住键配置 | 使用兼容路径点队列；不改虚表或到达代码 |
| 独立超武栏 | 使用现有功能开关 | 已接独立显示、拖动、停靠、折叠及既有超武命令 |
| 原生视野 / 地图缩放 | 可保存缩小、放大、恢复键 | 尚未完成无代码补丁迁移，开关禁用、快捷键不注册 |
| 原生高分辨率小地图防抖 / 重影修复 | 无 | 尚未迁移，原生Hook不安装 |
| 隐藏原生侧栏 | 可保存切换键 | 尚未迁移，原生布局不改动 |
| 单机暂停 / 逐帧 | 可保存暂停、逐帧键 | 尚未迁移，原生暂停门不安装 |

原生缩放、侧栏、暂停的快捷键使用和其他单次操作相同的配置框，可预先保存；界面明确显示未迁移，当前不会接管按键。“地图锁放”按地图缩放处理。

缩放与侧栏归视频设置；下令、队形、巡逻和暂停归控制设置。新功能继续使用既有输入、自动保存、冲突处理、GameRuntime调度和单位命令仲裁，不建立另一套专用面板或命令桥。

## 更新与验证

关闭工具箱并退出游戏，再成套替换 RA2Toolbox.exe、GameRuntime.dll、GameRuntimeHost32.exe，然后重新启动游戏。旧代码补丁Runtime可能被游戏进程保留，严格版不会尝试替旧模块恢复补丁。

严格核心931项受控检查通过，包含安装/恢复、代码/虚表、非法地址、有效租约和旧ABI；拒绝不会触发OS调用。Windows x86/x64共享结构709项检查通过。生产交叉编译、PE导出、架构和系统依赖检查另附构建结果。本轮未执行真实Windows游戏或联机验收。

MOControls1 包含代码补丁，不能用于验证严格架构。本版只交付上表已完成的无代码补丁路径，其余保留明确缺口。
