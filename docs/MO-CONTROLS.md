# MO 操作、地圖視角與獨立超武面板

本頁對應目前 `1.0.41-pre.1` 操作分支（Assist92）。新 Web 控制臺沿用原有功能開關及設定檔；更新時成套替換 `RA2Toolbox.exe`、`GameRuntime.dll`、`GameRuntimeHost32.exe`，Web 版本另需同包的 `WebView2Loader.dll`。本頁按目前原始碼核對操作，不代表已完成 RA2OL 雙機或現場畫面驗收。

## 模糊下令、區域分配、巡邏及快速占位

先在「控制」啟用相應開關，再選中己方單位操作。前三項預設關閉；快速占位共用「隊形排列與快速占位」總開關。

| 功能 | 預設手勢 | 操作結果 |
| --- | --- | --- |
| 模糊下令 | Ctrl＋中鍵 | 按住預覽游標附近的搜索範圍，鬆開中鍵後分組攻擊合適目標。 |
| 區域目標分配 | Shift＋中鍵 | 按住並拖過目標區域，鬆開後按單位原生能力分配攻擊、進入、占領或維修。 |
| 自訂巡邏圈 | Z＋中鍵 | 點按建立方環；拖直線建立長條矩形；繞回起點的自由軌跡建立閉合路線。鬆開後建立原生規劃路徑。 |
| 快速占位 | 純中鍵 | 在「隊形排列與快速占位」展開子設定。點按螺旋占位，拖線按弧長排位；步兵每格最多三個，車輛和飛機各一個，空地分開。 |

每項均可更改「按住鍵＋滑鼠鍵」。滑鼠可選中鍵、側鍵1／2、右鍵、左鍵或停用；按住鍵留空表示純滑鼠。重複或不相容的手勢會顯示配置衝突。巡邏手勢預設的 Z 可自行更改，原生規劃提交鍵則跟隨遊戲設定。

按住期間會持續更新輪廓，目標分配計算另行節流；停手時仍保留末端。Esc 或玩家後續手動命令會停止尚未送出的部分。已成功送入原生佇列的指令／規劃節點無法靠取消預覽撤銷；已有規劃圖或無法確定所選單位狀態時，可能拒絕建立新巡邏。

區域分配會按本家可進入建築的相容性和實際餘位分配；吸收型建築會輪流取得可進入單位，已送出但尚未到達的本工具命令也計入預留。這不會把不相容單位強制塞入建築。

### 七項「下令與巡邏參數」

在「控制」展開此組。這些參數不代替功能總開關，修改後自動保存。

| 參數 | 預設 | 可選範圍及含義 |
| --- | --- | --- |
| 模糊搜索範圍 | 4格 | 2–16格，搜索方塊的**全邊長**，不是半徑。 |
| 每組單位數 | 4 | 2–16；控制模糊分組，亦用於區域普通目標的首輪分配。 |
| 點按巡邏大小 | 4格 | 2–16格，方環／長條的全寬；半寬用整數除以2，所以設定5時半寬仍為2格。 |
| 軌跡採樣間距 | 2格 | 1–8格；拖曳巡邏的採樣間隔，末端仍會保留。 |
| 首尾閉環距離 | 3格 | 2–16格；起點、終點距離小於設定值時，嘗試保留閉合軌跡。 |
| 巡邏節點間距 | 3格 | 2–16格；控制閉合軌跡路點密度，最多16節點。 |
| 自動提交巡邏計劃 | 開啟 | 開啟後，驗證本批閉環完成才自動提交。關閉只停止工具箱自動提交；玩家釋放遊戲原生規劃鍵仍可能按原生語義提交。 |

模糊／區域／巡邏手勢固定使用開始時的整組參數。拖曳／待發令期間改配置會取消尚未送出的部分，避免混用新舊路徑。

## 高危：地圖視角縮放（實驗性功能）

在「實驗性功能」啟用「視角縮放」，選擇以下11檔：

**全圖（MAX）、50%、66.7%、75%、80%、100%、125%、150%、200%、300%、400%。**

目前新 Host 使用原生**地圖區域縮放**：視野拉遠時，遊戲先繪製較大的地圖光柵，再縮至螢幕上的地圖區域；建造欄與窗口介面維持物理尺寸，滑鼠位置同步映射。地圖內原生繪製的世界標註仍可能隨地圖縮放。這與舊版重建整個 `ChangeResolution`、連建造欄一起縮放的方式不同；舊整屏路徑只供不支援完整新握手的舊 Host 相容。

| 預設快捷鍵 | 行為 |
| --- | --- |
| Ctrl＋Alt＋減號 | 往較小倍率切換，鏡頭拉遠；50%的上一檔為MAX。 |
| Ctrl＋Alt＋加號／等號鍵 | 往較大倍率切換，鏡頭拉近。 |
| Ctrl＋Alt＋退格 | 恢復100%。 |

快捷鍵可在同組修改，僅啟用縮放時註冊。66.7%使用1.5倍地圖光柵。MAX依**目前地圖範圍與可用視區**計算適配倍率；原生光柵每軸最多8192像素、總量最多4000萬像素，超過上限會限制可繪尺寸，因此超大地圖不保證整張都能裝進一屏。拉遠需要繪製更多地圖內容，不代表遊戲幀率會提高。

縮放會自動維持所需的小圖邊界防抖：地圖某一軸小於視口時，該軸固定在地圖中心，另一軸仍可拖動。獨立的「高危：小圖相機邊界修正」開關預設關閉，供不使用縮放時另行啟用。切屏、暫停或觀戰不應直接撤掉同進程仍在使用的視角資源；其他程式改寫入口、原生版本不相容或無法確證安全還原時，會顯示錯誤／等待並保留尚被引用的資源。

## 高危：側欄顯示實驗

同在「實驗性功能」，先勾選「啟用側欄顯示實驗」。它有獨立開關，無需先啟用縮放；預設 **F11** 依序循環三態，按鍵可更改：

| 模式 | 顯示及操作 |
| --- | --- |
| 完整側欄 | 保留原生雷達、頁簽、建造圖示及側欄。 |
| 只保留雷達 | 保留側欄頂部雷達／按鈕，隱藏下方建造欄；下方露出區域可作地圖使用。工具箱世界疊圖避開原生雷達區。 |
| 隱藏側欄 | 整條側欄隱藏，地圖使用全寬。 |

切回完整模式後，實驗總開關仍開啟，F11繼續可用。此項會調整原生地圖範圍、顯示表面及入口，保持高危／實驗標記；遇到外部Hook或還原失敗時，請以狀態文字為準。

## 高危：單機暫停與逐幀

在「實驗性功能」啟用「暫停與逐幀」。**只支援單機／戰役，聯機拒絕啟用**；會修改原生主循環入口。

- 預設F5：暫停／恢復。
- 暫停後預設F6：前進一個模擬幀。
- 兩個鍵均可修改；需要遊戲位於前台且對局可用。切出遊戲或打開原生選單會自動恢復運行，取消待步進，保留已安裝入口以便回到遊戲後繼續使用。

逐幀指模擬前進，不是每按一次保證只呈現一張螢幕畫面。狀態列會顯示未支援、入口失敗或步進異常。

## 飛機路徑點：事件兼容與原生補丁

在「控制」的「飛機路徑點」選擇模式。選中己方飛機，按住路徑點鍵並在地面依序點下移動位置，鬆開鍵後接續執行。按住鍵留空時跟隨遊戲原生路徑點／規劃鍵；可填自訂按住鍵。攻擊／物件命令會結束路徑編輯，後續手動移動、攻擊或停止命令優先。

| 選項 | 目前實作與限制 |
| --- | --- |
| 關閉 | 不接管飛機路徑點。 |
| 兼容路徑點 | 透過普通原生移動事件逐點接續，單機／聯機沿用事件通道，不改寫飛機程式碼入口。 |
| 原生事件兼容（舊原生優先） | 保留舊配置選項名稱；目前同樣走事件兼容接續，不安裝原生下單／到達補丁。 |
| **高危：原生下單補丁** | 啟用原生飛機下單入口補丁；未啟用完整到達補丁。聯機效果未實測確認。 |
| **高危：完整原生補丁** | 同時啟用下單及本機到達處理補丁，可能影響聯機同步，需自行實測。 |

**設定自訂路徑點按住鍵時，改走事件兼容接續**；即使保留原生補丁選項，也不會使用上述原生入口路徑。事件入隊成功只代表命令已交給遊戲，不保證飛機已經抵達；長時間無法到達時工具箱會停止重複下令。

## 可拆離的獨立超級武器面板

在「視頻」啟用「獨立超級武器面板」，可與只保留雷達／隱藏側欄搭配使用。它保留原建造欄超武圖示，不取代原生超武本體。

- 左鍵點可用超武：進入原生目標光標，再在遊戲地圖選位置。
- 右鍵：取消目前超武選擇。
- 拖動標題可把面板拆離並移到遊戲窗口內其他位置；標題右側按鈕可切換停靠／分離及收起／展開，位置和狀態會保存。
- 滾輪查看更多超武；圖示素材不可用時以名稱回退。面板隨全體覆蓋層顯隱，預設使用鍵盤左上角的 **波浪號／反引號鍵**，可在設定更改。

只有就緒、仍屬目前玩家的同一超武才接受點擊；畫面中的舊項目或被替換的超武不會僅憑清單序號發射。

## 既有建造、科技與光標行為

原生事件「任意建造」會匹配目前建築／防禦欄已完成的產品。預設Ctrl＋Alt＋G開啟藍色地基預覽，左鍵才送原生Place；右鍵、Esc或再次按鍵取消。原生建造、維修、出售、規劃或超武游標活動時拒絕開啟；切換欄位、產品或對局會取消。藍框表示地基形狀，不代表所有地面都合法。

原生科技面板模式每個觀測到的新遊戲幀補回缺失的允許圖示，已有圖示不重插；只對缺失項重新查合法性和工廠，同幀補全至每欄原生75項上限。科技模式、科技加强及它們的高危／實驗選項依各自開關選擇，不由本頁手勢自動開啟。

HideCursor不標高危；隱藏原光標時，單位名稱與建造欄價格提示框修正仍保留。控制臺目前有15組收納；主開關保持可見，正常子配置／狀態可收起，真正應用或還原錯誤會自動展開，解除後恢復原收納偏好。
