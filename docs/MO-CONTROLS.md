# MO 操作与视野迁移

基线：Hotfix33 `17ee48810d33d47203d52893d3b0472d992f3a11`。
行为参考：MagicShiba/MO_ExperienceEnhancements 固定提交 `33ed558bd38f36b5012eddcc9c0fb109cc68e38a`。

本轮按现有工具箱架构适配，所有游戏命令继续经过 GameRuntime 的事件构造、队列和单位仲裁。通信协议升级至 Assist84，更新时须成套替换程序、DLL 和 32 位宿主。

| 功能 | 操作 |
| --- | --- |
| 地图视野缩放 | 实验性功能页启用；25 / 33 / 50 / 67 / 100 / 125 / 150 / 200% 与全图；Ctrl+Alt+减号/加号，Backspace 恢复100% |
| 模糊下令 | 控制页启用；Ctrl+中键按住预览，松开在附近分组攻击 |
| 区域目标分配 | Shift+中键点按或划过目标；按单位原生能力分派攻击、进入、占领、维修 |
| 快速占位 | 队形排列开关内；裸中键点按螺旋占位，拖线按弧长排位；步兵3/格，车辆和航空1/格，空地独立 |
| 自定义巡逻圈 | Z+中键点按生成小圈，直划生成矩形圈，闭合轨迹生成自由形状；最多16原生规划节点 |
| 小地图大视野防抖/重影 | 原生相机退化轴居中；缩放使用独立增量画面，地图外区域清理，呈现结果不反馈为原生滚动输入 |
| 飞机路径点 | 原生优先模式开放 AircraftType 的原生规划入口；普通模式不再同时装到达推进补丁 |
| 独立超武栏 | 实验性功能页启用；标题拖动、停靠、折叠和滚轮；左键选择原生目标光标，右键取消 |
| 单机暂停逐帧 | 开关启用后 F5 暂停/恢复，F6 前进一个游戏帧；LAN/Internet 禁用 |
| 隐藏侧栏 | F11 循环完整侧栏、雷达与按钮、隐藏侧栏三档；同步地图画布、鼠标边界与布局恢复 |

“地图锁放”按参考库的地图缩放处理，与视野缩放共用实现。

新操作默认关闭；快速占位复用队形开关。Esc 取消新操作的预览，手动操作优先。原有增强中键轮询与新手势共用归属判断，避免同一次输入重复发令。

独立超武栏保留原防御页图标；仅提供PCX而没有SHP的条目使用名称回退。巡逻的原生已有闭环、构造中途手动接管、提前松Z以及平台修改过的绘制入口仍需实机验收。精确签名不兼容时拒绝安装对应补丁。

交叉编译、结构布局与受控逻辑检查不能证明真实 Windows 游戏视觉或联机同步。本轮未运行完整游戏。
