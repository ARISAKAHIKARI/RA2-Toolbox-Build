# 操作配置與獨立超武面板

本分支合入 [adaae2b3f4a880d1a5f0e9b87f905b69f80b1329](https://github.com/ARISAKAHIKARI/RA2-Toolbox-Build/commit/adaae2b3f4a880d1a5f0e9b87f905b69f80b1329) 的新增操作功能及所需前置實作。依使用者明確選擇，保留此分支已確認的 Hook、光標、原生建造／科技與渲染修正，不導入該提交的全局禁止程式碼／虛表 Hook 政策。

通訊配套為 Assist89、Runtime4、Entry3、Cursor155。更新時退出遊戲與工具箱，成套替換 RA2Toolbox.exe、GameRuntime.dll、GameRuntimeHost32.exe。

## 使用方式

| 功能 | 位置及預設操作 | 行為 |
| --- | --- | --- |
| 模糊下令 | 控制頁，Ctrl＋中鍵 | 按住預覽、鬆開提交，將所選單位分組攻擊附近合適目標 |
| 區域目標分配 | 控制頁，Shift＋中鍵 | 沿軌跡收集目標，按原生能力分派攻擊、進入、占領或維修 |
| 自訂巡邏圈 | 控制頁，Z＋中鍵 | 點按建立小圈，拖曳建立矩形或閉合軌跡；以原生規劃事件建圖 |
| 快速占位 | 控制頁「隊形排列與快速占位」，展開子設定；預設純中鍵 | 點按螺旋占位，拖線按弧長排列；步兵每格最多三個，車輛與飛機各一個，空地分開 |
| 獨立超級武器面板 | 影片／顯示設定的獨立面板開關 | 顯示可用超武；左鍵選原生目標光標，右鍵取消超武選擇；支援拖動、停靠、摺疊和滾輪 |

新操作預設關閉，快速占位共用原隊形開關。四組手勢共用現有按住鍵及滑鼠配置，可選中鍵、側鍵、左右鍵或停用；空按住鍵表示純滑鼠。設定自動保存，Host 和 Runtime 使用同一份手勢規則，衝突不重複發令。九組子設定收納保留，快速占位的配置收入隊形組。

巡邏不直接私寫任務、PlanMgr、節點或亂數資料，也不私寫網路佇列。選中單位已有非空規劃圖、讀取不完整或存在不相容的待提交圖時拒絕新建，避免把舊閉環誤認為新路徑。Esc 或手動接管停止尚未送出的部分；已進入原生佇列的指令不能視為撤銷。原生規劃按鍵由實際遊戲設定解析，不固定假定為 Z。

超武面板保留原建造欄圖示。點擊提交前及遊戲執行端都核對 index、instance、type，避免畫面更新期間發到被替換的超武。素材不可用時以名稱回退。面板沿用全體覆蓋層顯隱鍵。

## 進階與實驗功能

以下三組收在「實驗」分類，預設關閉：

| 功能 | 操作 | 實作及限制 |
| --- | --- | --- |
| 視角縮放 | 開啟後選50/75/100/125/150%；預設Ctrl+Alt+減號／加號／退格 | 需有Zoom介面的CnC-DDraw；重建整個邏輯顯示解析度，原生建造欄也一起縮放。版本、比例或視窗不兼容時拒絕切換。 |
| 高危：側欄顯示實驗 | 先啟用實驗，完整／隱藏二態；預設F11切換 | 隱藏的是右側建造欄，會擴展原生地圖範圍及顯示表面。13處程式碼修改，完整原生Render結束後才改動。外部Hook／佈局衝突或原生異常時停止切換；不能證明安全還原時保留表面與Runtime直到遊戲結束。 |
| 高危：單機暫停與逐幀 | 開啟後預設F5暫停／恢復、F6前進一幀 | 僅單機／戰役（session0/5）；修改55D360主循環入口。失焦或開原生選單自動恢復運行，取消待步進，保留已安裝Hook。聯機拒絕。 |

倍率、顯示模式與按鍵保存到設定。側欄有獨立啟用選項，首次局中啟用即建立Runtime需求；完整側欄狀態仍可接受F11，不會因關回完整而失去熱鍵。

## 任意建造與科技圖示

原生事件建造方式改為自動匹配當前**建築欄／防禦欄**各自已完成的產品，清單僅顯示資訊。Ctrl+Alt+G開啟藍色地基預覽，左鍵才送原生Place；右鍵／Esc／再次按鍵取消。原生建造、維修、出售、規劃或超武游標活動時拒絕開啟，工具箱不清掉原生工具。切換欄位／產品／對局即取消。藍框表示地基，不表示所有地面合法；自訂未知地基只顯示提示。

科技面板在每個觀測到的新遊戲幀補全缺失的允許圖示，已有圖示不重插。只對缺失項重新查原生合法性與工廠，同幀補齊，不分八項等批次；保持每欄75上限。普通訊息／輪詢調度保持既有政策，沒有為補圖示新增幀Hook。

HideCursor不標高危，名稱／價格提示框修正繼續保留。模糊／區域／巡邏輪廓以16ms預覽節流跟隨最新游標，目標分配維持獨立較慢計算；快速占位保留所有有效軌跡樣本和停手末端，seqlock碰撞沿用上一份完整畫面。唯讀持有容許短暫心跳抖動，事件提交仍使用150ms及完整原生權限檢查。
