## 1.0.2 更新

- 修复 Shift 五连点设置仍检查已删除鼠标 Hook 句柄的问题；修改设置不会再把已勾选的连点误关。若旧配置已被误写为关闭，重新勾选一次即可。低绘制帧率下，按键观察保持最多 4 ms 的目标间隔，复用原有计时器。
- 战术面板新增 **热键冲突时全部执行**，默认关闭，即时生效并自动保存。开启后，可配置键盘快捷键及增强鼠标组合的匹配功能依次通过既有通道提交，等待前项回执，避免覆盖邮箱。两种飞机模式可用相同按住键。
- 敌方名称去掉 P1/P2 等编号，保留单位名称和玩家颜色符号，刷新率保持不变。

同一单位的后续命令可能覆盖前项；仍保留每帧额度、原版合法性、捕获身份、时效与手动取消检查。Assist 协议升级为 42，须退出旧工具和游戏后整包更新。详见 [连点与冲突处理](docs/HOTKEY-AND-SHIFT5.md)。

## 继承 1.0.1 的敌方位置标记

在战术面板的显示设置勾选 **敌方位置标记（包含未揭示区域）**。默认关闭，即时生效并自动保存。当前画面内的敌方单位与建筑按玩家颜色显示位置符号和类型名称，包含未揭示区域；排除己方、盟友、中立与运输中的乘员。

刷新率与现有覆盖层一致：共用原有 FPS 设置、采样时钟、Motion 插值和绘制窗口，同一逻辑帧内也更新坐标。仅使用统一外部读取器，不修改迷雾，不调用地图揭示，不发游戏指令或新增 Hook。菜单、失焦、读取失效和过期时隐藏，裁剪到战场视口。详见 [敌方标记说明](docs/ENEMY-MARKERS.md)。

## 继承 1.0 的单位清单配置

战术助手新增“功能单位清单”，飞机、飞碟、磁电和高级移动等功能可按类型清单选择处理对象。选择功能、填写单位 ID，再按需勾选自定义开关。每项独立，支持离线编辑、即时生效与自动保存。

| 可配置功能 | 可配置对象 |
|---|---|
| 飞机分配攻击、飞碟主武器、磁电轮换、高级移动攻击 | 各功能的源单位 |
| 自动装车、高级进驻 | 乘员与载具/建筑分别配置 |
| 智能卸载、逃生助手 | 载具与乘员分别配置 |
| 变卖战车、维修 | 载具或建筑类型 |

共 14 项新清单。未勾选自定义时保持原有识别；勾选且清单为空则不处理。每项最多 512 个 ID，支持大小写归一和中英文分隔符。矿车、矿场、自动 CS、组合选兵保留现有配置。

类型清单只限制参与对象，不给普通单位新增武器或能力；原版所有权、武器、进入、容量、Dock、维修与出售条件仍需通过。输入捕获与最终提交前复核最新名单，宿主重连/新局清除缓存，序号重复也不会误用旧清单。

## 安装与配置

完整解压运行包，退出旧工具和游戏后更新，运行 `RA2Toolbox.exe` 或 `Start-Message.cmd`。可以迁移旧 `Assist.ini`、`settings.ini` 和 `cache/unit-icons`。普通设置即时生效并自动保存。

十项增强鼠标键各自可配为停用、中键、侧键 1/2、右键；组合键可留空。未新增可配置优先级仲裁。右键保留原版点击，工具观察状态后追加自己的原版事件。

只注入单个 GameRuntime.dll，各功能共用管理器消息入口与原版事件提交，不安装功能级 Hook 或改写游戏代码。外部读取器共用连接管理，各任务独立采样缓存；部分装车、维修、卸载/逃生业务仍在 Runtime 中。

## 验证与构建

本版通过 **880 项实际 x86 DLL 模型用例、60 个便携测试程序、26 项源代码/UI 检查和 2 项模拟 Win32 读取测试**。199 个控件通过 12 种视口、2292 项可达性检查。新标记测试覆盖敌我变化、身份复用、菜单/重连、同帧位置与插值、视口裁剪、容量和损坏输入；1000 次 2 ms 调度模型不等于实测 500 FPS。本版新增80项DLL组合续项用例；继承的类型清单占130项，旧版800项均重跑。

模型不等于完整游戏；本版尚未完成 Windows 游戏实机、平台联机、LBW、屏幕捕获和实际延迟/帧率验证，因此发布为预发布版本。

使用 Zig 0.13.0，构建入口为 `source/build-zig.sh` 或 `source/BUILD_ZIG.cmd`。逻辑测试需要 Python 3/g++，DLL 模型还需要 unicorn/pefile 及自行提供的游戏 EXE。开发包与运行包解压到同一目录可提供完整构建资源；游戏本体不随包分发。

Release 上传附件仅为运行包，不包含项目源码和测试材料。engine/runtime 下的 Python 文件属于运行依赖。完整源码已展开提交，开发包另存仓库；GitHub 自动生成的 Source code 下载属于仓库快照。历史 payload/release 用于资源重建，当前代码以 source/ 为准。
