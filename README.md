# RA2 Toolbox 1.0.18 Beta

Windows 高刷光标、单位统计与战术助手。文件版本 **1.0.18.0**，Assist 协议 **51**。

- [完整运行包与更新包](https://github.com/ARISAKAHIKARI/RA2-Toolbox-Build/releases/tag/v1.0.18)
- [源码](source/) · [本版说明](packages/v1.0.18/RELEASE_NOTES.md)
- [位置/快捷键及验证边界](source/REVIEW-1.0.18.md) · [验证记录](source/verification/review-118/)

放大小地图支持位置预设与自定义坐标，自动避让空闲飞机按钮。轮选空闲飞机默认 Ctrl+Alt+P，可配置；隐藏指示器时热键仍可用。保留十项战术决策的计算位置配置，事件与选兵仍统一 GameRuntime。

退出游戏和工具后成套更新 EXE/DLL，保留配置和 cache。Zig 0.13.0 构建 source/build-zig.sh 或 source/BUILD_ZIG.cmd。

本轮为外部布局、设置、热键和静态构建验证；没有真实 Windows/LBW、双机联机或延迟验收。历史报告只对应相应版本。
